Katsuyo Furifont Sans, Katsuyo Furifont Serif, Katsuyo Furifont Display

These are custom font derivatives for Katsuyo Dojo. All fonts retain their
source font's SIL Open Font License 1.1. The reserved source family names
are not used as the derivative family names.

Text, group boundaries, and readings come exclusively from Katsuyo Dojo's
local reviewed usage-card and lexical/conjugation data. The upstream
dictionary datasets were not used. No external dictionary assigns readings.
The shared corpus extraction and its exact layout overrides are in
scripts/furigana-corpus.mjs and app/data/furigana-layouts.json.

Rebuild: npm ci; npm run build:furifont
Audit the served WOFF2: npm run audit:furifont
The build downloads and checksums its pinned base fonts when the temporary
directory cache is absent. Optional --base-sans=PATH and --base-serif=PATH
arguments use local copies after the same checksum validation.
The fonts preserve a true variable weight axis. Each exact reviewed pair
uses an explicit, one-based salt selector, without changing the source text.

app/data/furifont-manifest.json records source provenance, hashes, metrics,
selectors and measured ink reservations. app/data/furifont-runtime.json is
its compact browser projection, checked against the full manifest by the
font audit. audit.json records HarfBuzz shaping
and literal glyph-component checks on the actual delivered WOFF2 files.
