# 活用道場 Katsuyō Dōjō

一个独立运行的日语动词与形容词活用练习网站。课程内容对应 Yokubi，并以统一的学习路线、短轮次、自适应选题和即时拆解帮助学习者把活用规则练成直觉。

在线体验：<https://l-m-sherlock.github.io/katsuyo-dojo/>

## 特色

- 把完整活用拆成词类、词干、音便、接续、复合和例外等细分知识点
- 动词与形容词共用一条自适应路线；“全部课程／动词专项／形容词专项”只筛选课程列表，不改变当前题目
- 43 门课程按主要学习目标分为基础变化、可能与态、连接与条件、意愿与要求、动作与状态、综合运用六组；推荐顺序独立编排，先满足先修，再安排规则引入、复用与对照
- 「高かった」「読みたかった」「読まなかった」共用过去变化规则；「たい」「てほしい」的应用能力分别记录，并要求覆盖过去、否定和否定过去
- 一道题同时为多个知识点提供证据，并优先练习当前最薄弱的已解锁知识点
- 按明确的先修依赖开放知识点，无关课程的薄弱点不会成为全局解锁障碍
- 分别显示本轮重点掌握度、本课达标数量和全局唯一知识点进度；可能与态的后续活用按迁入的应用知识点与形式覆盖判定达标
- 学习轮次最多 12 题，按 3:1 穿插当前重点和已学知识点；当前可推进的不同例词练完后提前结束，不用已达标题补满。短轮次显示实际题数，规则恢复阈值与独立复测要求保持不变，见 [短学习轮次](docs/short-learning-rounds.md)
- 在满足待补的形式覆盖和例外词薄弱点后，优先选本轮未出现的词，再避开最近 36 道已作答原题使用的词；同一词的不同变形一起避重，候选不足时允许复用。选词不依赖浏览器语言，同等条件下随轮次变化
- 知识点达标后会在题目之间重排剩余题位；跨课程时提前结算，避免继续刷已掌握内容
- 不使用复习间隔、到期队列或遗忘曲线；作答时间不参与置信度、选题或解锁
- 全部达标后按课程轮换巩固，每轮练满 12 题；答错后优先加强薄弱知识点
- 看过提示即按提示作答计分，收起提示不会取消记录；不规则分类的历史覆盖保留，近期错误会降低掌握程度
- 支持键盘作答、假名或汉字答案、保守错误归因和即时规则拆解；拆步判分后按 Enter 进入下一步，完成拆步后再按 Enter 进入下一题
- 对能准确定位的错误，只更新错误步骤与明确写对的步骤；共享规则与应用能力无法区分时，先提供中间形式拆步确认，不猜测归因
- 五段受身构造出现词干与接续混用、且后续形式完整时，先定位到受身阶段，再分开检查ア段词干和受身接续。阶段定位本身不更新知识点分数；受身＋たい＋否定过去会明确练习たい这一步，各步只评估新增操作，不给已提供路径的多步组合加分
- 完整词干之后漏接续、基础词尾漏末字，可定位到尚未完成的接续；仅确认可见的词干与音便，不推断词类或尚未写出的浊化。动词及い／な形容词的完整形式混淆只更新本题要求的接续，词类误用同时匹配时保留歧义
- 常见词干错行、原形词尾残留、音便选错，以及接续内部的片段遗漏、清浊音、促音、重复和颠倒，按实际操作边界归因。旧的精确诊断优先；存在多个成因时保留未归因，不靠缩小评分范围消除歧义
- い／な形容词否定过去题若恰好答成正确否定形（含「じゃない」），确认已完成的否定步骤，只检查剩余的过去变化；未确定的错误暂不扣分，拆步不重复计算前置证据
- 完整中间形式会确认已经完成的变化，只检查剩余步骤；原词漏字且词尾完整、修正唯一时提示重输。无法唯一定位的错误暂不扣本题重点知识点，支持拆解的复合形式提供中间形式继续检查。各步使用实际的中间词，不重复计算前置证据，不增加今日题数或连对；可跳过剩余拆步查看解析
- 全部 134 种活用形式都有基本操作路径。多处错误先展示可观察的差异，再自动补查未确认的词干、音便或接续；给定词类后的旧拆步也使用同一套路径。每个节点只检查一次，同一知识点每轮拆步最多记录一次；无法辨认的基本步骤说明原因后结束，可随时跳过
- 原词中不参与活用的部分出现一次字符替换、遗漏、内部插入或相邻颠倒，其余答案完全匹配、纠正目标唯一且无明确语法诊断时，提示疑似笔误并允许修改重交；此次提交不计入答题或知识点统计。短词根证据不足、跨词干边界的编辑、词尾、音便与不规则词干不适用，修改后仍须正常判分，已使用的提示记录保留
- 部分正确仅在完整答案精确匹配受支持的同类变化时计分，保留提示权重；不根据局部字符串猜测，也不给揭晓答案计部分正确
- 原题精确匹配派生词过去变化冲突时，优先检查中间词类和过去变化；前部损坏、多个候选阶段或其他合法表达冲突保留完整检查，跳过的前段不自动加分。规则与保护边界见 [阶段优先补查](docs/probe-routing.md)
- 学习记录只保存在当前浏览器，不需要账号或后端服务
- 支持将练习进度导出为 JSON，并在其他浏览器或设备上导入恢复
- 作答日志记录原题、拆步、输入重试与拆步结束，保存实际知识点更新的前后快照；可在「知识进度 → 作答日志」查看，也随备份导出。最多保留 500 条并受容量上限约束，裁剪数量可查；旧备份不补造历史。字段与追查方式见 [作答日志](docs/practice-log.md)
- 用于避免重复出题的最近词条窗口随进度保存、导出和恢复；正确、错误和揭晓答案各记一次，输入重试与拆步不记入该窗口。旧备份从空窗口开始积累，不改变已有掌握度
- 多标签页通过 Web Locks 串行保存，旧页面发现进度冲突后暂停，重新加载即可恢复练习
- 浏览器存储不可用、写入失败或不支持 Web Locks 时，保留本页练习记录并提示导出备份；关闭页面前需手动导出

## 练习范围

保留 122 种动词形式、12 种形容词形式及分类练习。项目聚焦给定词的构形训练，不是一套全面的句法或语用课程；排序依据词形变化所需的基础与复用关系，不因句子语用复杂度而推迟构形练习。各表达的过去、否定、否定过去安排在该表达所属课程中，按先修条件逐步开放。

题目按当前词义审核：区分构形不支持、词义不适用和需要语境。156 个动词与 91 个形容词都有审核记录；需要语境的搭配只使用已审核的日常场景，语境在题干中直接显示并保存到作答日志，不计为提示。完整词形识别独立于出题筛选，仍能说明答案属于其他形式及其词义限制。审核方法与筛选结果见 [题目适用性审核](docs/eligibility-audit.md)，小候选池的常用词增补见 [自然例词增补](docs/natural-word-supply.md)。

形容词内容涵盖い／な形容词分类、否定、过去、否定过去、て形、条件形和副词形，并包含「いい／かっこいい」的「よ」系变化及「きれい／嫌い」等分类例外。

## 课程阶段

分组说明每门课主要学什么；顺序说明先具备什么、能复用什么；解锁则检查实际先修和学习进度。分组与顺序分别配置，同主题不强制连续，也不要求整组全部达标后才能学习下一组。

| 阶段 | 课程数 | 主要学习目标 |
|---|---:|---|
| 基础变化 | 11 | 词类识别，以及基本肯否、时态、礼貌、修饰和连接形式 |
| 可能与态 | 5 | 可能、受身、使役与使役受身 |
| 连接与条件 | 9 | 否定连接、条件、让步、同时动作与列举 |
| 意愿与要求 | 10 | 愿望、意向、尝试意图、请求、命令、禁止、许可与义务 |
| 动作与状态 | 7 | 动作状态、授受、尝试、完成、准备、方向与程度 |
| 综合运用 | 1 | 愿望、尝试、状态、授受的四类多步组合 |

实际先修排在依赖它的内容之前，原生基础规则先于派生结果的后续应用；共用规则在首次需要时引入。课程同等就绪时，再按词形训练目标、规则复用和形式对照安排，主题相邻是次级考虑。阶段标签不表示严格语法分类或难度等级，各表达组的先后是推荐顺序。

当前将可能、受身、使役、使役受身安排在基础变化之后的第 12–15 课，第 16 课「可能与态的后续活用」紧随其后，形容词副词形仍为第 6 课。共用的五段 e 段词干由第 12 课可能形引入，第 19 课ば形及后面的命令形复用。可能与态组内的顺序用于教学对照，不额外建立课程间的硬依赖。

一门表达课即使包含后续的过去、否定和否定过去，也按它引入的基础目标归组，不因含复合题就归为“复杂组合”。课程内的后续变化仍按先修条件逐步开放。完整 43 课顺序与原则见 [统一课程规划](docs/unified-curriculum-plan.md#3-当前阶段与推荐课程顺序)。

课程重排保留全部课程 ID 和原知识点 ID，新增三类常见多步组合后共 134 种活用形式；独立评估升级另行区分整题成绩与辅助练习，详见下文。

## 进度迁移

新版使用 v7 独立存储键，自动读取本地 v6、v5，也支持导入旧版 JSON。课程统一迁移保留等价规则统计；旧复合统计，以及曾被连用接续题混入的ます统计，保留在历史快照中，新的规则或应用缺口单独确认。不会把旧汇总统计复制到多个新知识点。原有每日答题数和历史课程访问权限保留，课程访问权限不等于先修达标。

导出文件包含迁移报告与原始历史快照。旧标签页写入 v6、v5 不会覆盖 v7；页面会提示旧版记录发生变化。课程重排与迁移约束见 [统一课程规划](docs/unified-curriculum-plan.md)。

课程编排标记为 `curriculumVersion: 3`。已有显式课程访问权限原样保留；已引入五段 e 段词干的旧记录，按来源版本保留相应访问：版本 1 或无版本标记保留命令形，版本 2 保留ば形。版本 3 在可能形课学到该词干，不会因此提前开放后面的ば形或命令形。知识点 ID 与作答统计不变。

## 独立评估与复测

拆步、提示和过早重练只进入辅助练习记录，不增加独立掌握度，也不完成整体应用或形式覆盖。整题失败会保留待复测任务：需要换词、保持同目标与同操作路径，间隔至少两道其他整题后无提示答对。确实只有一个同规则词时，完成两道其他整题后即可同词复测。所有复测只依据作答顺序，不使用时间延迟或记忆衰减。

独立评估记录使用版本 2，兼容版本 1。收紧题库后，同规则路径没有任何适用题目的旧复测任务会转入 `suspendedPending`，保留原有失败、得分、日志和题数锚点，不视为通过，也不阻碍继续学习；目录恢复兼容题目后自动恢复待复测。

知识进度可查看待复测与两类证据，作答日志记录每次帮助条件、独立/辅助变化和任务状态。旧日志中能可靠核验的辅助加分会纠正，无法核验的历史统计保留并说明来源。计分、调度和迁移的完整口径见 [独立评估](docs/independent-assessment.md)。

课程已开放后，如果旧先修掉分，会先安排能实际恢复该知识点的基础题，再继续当前课程；分类缺口使用分类题。页面与模拟器共享选题逻辑，课程续练信息随进度保存。实际存档与恢复验证见 [先修恢复与课程续练](docs/prerequisite-recovery.md)。

自适应还会优先恢复其他课程中曾达标又退步的知识点。已知的「い形容词＋なら」分类误扣，会依据可核验日志校正并保留审计记录，详见 [全局恢复与なら校正](docs/global-recovery-and-nara-correction.md)。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（通常为 `http://localhost:5173/katsuyo-dojo/`）。

## 验证

```bash
npm test
npm run test:independent
npm run audit
npm run audit:diagnosis:parallel
npm run audit:paths:parallel
npm run simulate:perfect
npm run simulate:mixed
npm run typecheck
npm run lint
npm run build
```

错误模式生成审计将声明的错误模式展开到题库，批量验证整题与拆步的归因、差异提示、独立补查、阶段定位、部分正确和计分，并输出明确约定的回归、探索缺口、逐目标形式的模式数量和知识点覆盖。包括同一接续内两处不连续的字符遗漏，例如「させられる → せれる」；必须直接归因的用例不能仅靠拆步回退通过。独立适用性测试检查每个支持的形式是否生成对应错误族。用法与边界见 [错误模式生成器](docs/error-pattern-generator.md)。

诊断路径审计另用独立的正确操作约定，检查全词库的合法变体、单处错误及基本拆步，并在每种结构的代表词上组合两处、词汇与活用混合、三处以上和固定种子模糊输入。它要求完整反馈、有限补查和正确计分，能阻断“没有扣分但也没有帮助”的退化。生成结果、反例缩减及回放见 [诊断路径与自动检查](docs/diagnostic-paths.md)。CI 并行运行全部轻量回归测试及构建检查。大规模代表性审计和全词库审计分别通过 Extended representative audit、Full diagnosis audit 手动运行；发布复用同一次 CI 的构建产物，不重复验证。详见[验证与发布](docs/publishing.md)。

独立回归另保留三个 subagent 先写预期、后跑分析器的 348 个种子，以及 96 个汉字对照与 48 条完整拆步流程。原始预期和复核理由分别保存，避免仅靠同源生成器报告覆盖率。范围、发现和复现命令见 [独立错误输入复核](docs/independent-input-review.md)。

## 项目结构

- `app/`：练习界面、知识点模型、题目编排与本地学习状态
- `app/lib/unified-*.mjs`：统一课程、实际操作步骤、共享知识点、课程达标与历史迁移
- `app/lib/practice-session.mjs`：页面与模拟器共用的轮次计划和转换规则
- `app/lib/learning-*.mjs`、`retest-planning.mjs`：独立/辅助证据、持久化复测与调度
- `app/lib/profile-store.mjs`：存储错误处理与跨标签页写入保护
- `app/lib/diagnostic-*.mjs`：基本操作路径、差异反馈与拆步队列；`answer-analysis.mjs` 为页面和审计共用的判题入口
- `scripts/lib/diagnostic-oracle.mjs`：独立操作约定；`universal-error-cases.mjs` 负责输入变异与反例缩减
- `tests/`：自适应算法、知识映射、数据迁移、页面交互和活用规则测试
- `public/`：静态资源
