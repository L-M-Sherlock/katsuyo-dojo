# 连接与条件：审核完整的前后项

先确认任务课程要求哪一种连接关系，再写前后两个命题。词尾正确、两句各自通顺，还不足以成为可用的连接例句。

下文的“本课”指当前已接入的教学用义，不是课程扩展上限。发现其他自然用法时，按协调流程核实并同步扩展说明后再接入；用户已暂缓的具体配对仍保留暂缓状态，不因规则更新自动恢复。

- **なくて／ないで、ず／ずに**：判断前项未发生是后项的原因、伴随状态，还是列举事实。なくて的因果需合理；ないで不能统一写成禁止。ず／ずに偏书面，不按是否有に机械分成“因果／伴随”。规则不明可换自然的原词搭配，不能把思う当考える，或把待った译成“等到了”。
- **ば、たら、形容词条件**：核对假设、恒常结果或事后顺序。ば前项为同主体意志动作而后项为请求、命令或意向时要特别核查，优先采用明确的结果关系；不把所有ば＋意志后项一概判错。状态条件「元気なら」「天気がよければ」可自然提出建议。たら后项为过去事实时，不能擅自把它翻成尚未发生的假设。
- **ても／たって**：明确“通常以为前项会影响后项，但这里不影响”的让步关系。两件无关联的事硬接起来不够，例如“玩一整天也不会取消比赛”缺少自然的对立预期。可在短场景补足必要背景，不用长注释挽救任意拼接。
- **ながら／つつ**：本课练同一主体的同时动作；不借逆接或「つつある」渐变义充数。短时动作可与另一动作过程重叠，但需看实际句子；也不能把起床偷换成醒着、坐下偷换成坐着、进入偷换成身在某处。固定词义难写时交回未决项。尤其「いる」的普通ながら并行不能用「居ながらにして」的原状保持用法背书；睡觉义的寝る也不能借躺卧姿势的例句过关。
- **たり／ては**：たり用具体动作／状态作非穷尽列举，不要求每句固定两个たり，但句尾须完整。本项目 listing 引用的 Yokubi 第45课练ては反复；不能只写「〜ては困る／いけない」条件句。反复的后项可以是好事或坏事，不要求都有不理想结果。单在中文加“每次、总是”不等于日语已表达反复。

## 从本轮试稿学到的检查

1. 阅读日语原句，再看场景和译文：人物、肯否、量词和时态一致吗？「救助を待った」只说明等待，不保证已获救；不知道规则参赛不自动表示犯错。
2. 选词的助词按该词检查，例如「規則が分からず」不要机械沿用「規則を理解せず」的を。思う使用具体思想内容，不用「深く思う」替代“深入思考”。
3. 条件前后项都要有实际内容，不复用“就会顺利／还是没改变”给大量无关动词。写同一词的相关形式可复用背景，但逐句审核肯否与预期关系。
4. “场景可以补背景”不表示可以凭空为日语添加行为结果。译文只翻日语本身，短场景也不得与之相冲突。
5. 正文改写后同步核对读音，尤其ず形式「来ず＝こず」、促音与连浊。保留自然书写和片假名，不追求机械汉字比例。

作者自审和结构检查之后，审核者仍应检查实际生成的全部句子。对用義或自然度拿不准的固定组合，报告具体尝试、词义和可靠证据；不要替主代理改变课程或出题限制。


## 核对依据

[JPF 否定连接](https://www.jpf.go.jp/j/project/japanese/teach/tsushin/grammar/pdf/nk57_14-15.pdf)、[Vず（に）](https://www.kyozai.jpf.go.jp/kyozai/material/BMA00030/ja/render.do)；[JPF ば条件](https://www.kyozai.jpf.go.jp/kyozai/material/BMA00018/ja/render.do)、[东外大条件说明](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/083.html)；[东外大让步说明](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/084.html)、[国语研究所たって](https://mmsrv.ninjal.ac.jp/kamus/data/item3469.html)；[JPF Vながら](https://www.kyozai.jpf.go.jp/kyozai/material/BTS00121/ja/render.do)、[国语研究所つつ](https://mmsrv.ninjal.ac.jp/kamus/data/item3696.html)、[たり](https://mmsrv.ninjal.ac.jp/kamus/data/item3444.html)、[て](https://mmsrv.ninjal.ac.jp/kamus/data/item3474.html)。这些支持构式关系，不能替任何新写例句作自动批准。


扩写验收还要直接查看实际 `scene` 和 `translation`：不能出现“一边进行前项动作，一边完成后项动作”一类占位文字，也不能把词库多义释义（如“切；剪”）拼入句子。自审摘要若声称逐句完成，却实际只是统一替换前后项，应整批退回实质重写。只把生成结果静态展开为数组不能消除模板语义错误。


并行的时间尺度要具体说明：工作与上学可以在同一生活期间进行，不必精确同一秒；但这不允许把“进入后才浏览”“掉了钥匙才寻找”写成同时。始める可采用着手阶段的真实并行，出かける可采用同一时期反复外出与另一持续活动；仍逐句核对，不能只加“每次”掩盖先后。[JPF 的ながら说明](https://www.kyozai.jpf.go.jp/kyozai/material/BTS00121/ja/render.do)包含生活期间并行；[普通いる＋ながら的误用研究](https://eprints.lib.hokudai.ac.jp/dspace/bitstream/2115/43787/1/sekai.pdf)与[寝る等具体构式研究](https://nagoya.repo.nii.ac.jp/record/14971/files/k9886.pdf)说明不能机械互换ながら／つつ或借别的词义过关。
