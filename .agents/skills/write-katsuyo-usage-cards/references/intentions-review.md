# 意愿与要求专项审核

编写 `stageId: intentions` 的卡片时读取本文件。它补充 `editorial-review.md` 的完整句审核，不能代替词义／形式清单，也不能把程序结构通过当作自然度通过。先读活用器生成的整句，再按本课采用的表达作用审阅场景、译文、助词、语体与读音。

## 愿望族：主体和否定方向

| 目标 | 应表达 | 容易误写成 |
| --- | --- | --- |
| `tai` | 说话人希望自己做某动作或达到某状态 | 已经做了、能做、决定一定做，或第三人未经引语的愿望 |
| `taiPast` | 过去有过上述愿望 | 动作已经发生、成功或失败 |
| `taiNegative` / `taiNegativePast` | 说话人现在／过去不希望自己做 | 没做、不能做、禁止别人做 |
| `tehoshii` 族 | 说话人希望别人做，或希望无意志状态发生 | 对方已经做了、一定会做，或把「借りてほしい」写成“希望对方借给我” |

「たい」省略主语时仍须从场景确认是说话人的愿望。过去落在愿望上，不自动改变动作时态；译文不要补“终于、已经、没能”。「てほしい」中执行者、希望者、受益者和无意志变化的承受者分开判断；「壊れてほしい」是希望物品坏掉，不是希望某人把它弄坏。

重点逐句检查：

- `思う` 要保留“认为／相信”的命题层次，用「～と」等真实补语；不能机械当 `考える` 或套“想做”。
- `借りる` 固定按借入方向写，来源可用「から／に」；不能把“借给我”误写成「借りてほしい」，也不能把负面方向翻转成“不愿借出”。
- `忘れる` 的愿望可为忘掉痛苦，也可为不忘约定；否定形必须明确是“不希望忘记”，不写成已经记住或没有忘掉的事实。
- `死ぬ` 的肯定愿望需要明确寿终、危险、虚构角色或其他足以支撑语用的场景；不把植物枯萎、机器停止或普通“输掉”换成死亡义。
- `似る` 需要明确“谁像谁”和相似的方面；「に」通常标记所像对象，不要套用动作执行者模板。

愿望否定尤其要排除“能力不足”或客观受阻：钱包丢了、堵车、时间不够只能证明“付不了／赶不上”，不能直接证明“不想支付／不想赶上”。`間に合う` 的愿望应让人或明确的提交／出席事件成为自然主体，通常围绕“想赶上截止时间”；不要写成 `レポートが間に合いたかった` 这类主体不清的句子。逐句核对 `脱ぐ` 是否真在表达脱下衣物的愿望，清洁或天气理由不能与“不想脱鞋”互相冲突。

固定词义仍需检查及物性和搭配，不能因为目标活用合法就接受另一动词的句法：`動く` 是不及物，不能带「を」表示“活动身体”（那是 `動かす`）；`防ぐ` 要有自然的被防止对象和施事关系；`落とす` 是使物品掉落／遗失，不等于把东西放下（`置く`）。`持つ`、`住む`、`払う` 也要分别核对携带／拥有、居住地点和支付方向，译文不得扩大或缩小原句地点、对象和能力含义。

## `たがる`：可观察的第三人愿望

`たがる` 的本课用义是观察者描述第三人的愿望表现。主语可为人物、群体或明确的故事角色；场景须提供言语、反复请求、伸手取物、拒绝离开等可观察依据。裸形常写习惯或倾向，不能只用中文“现在很想”掩盖体貌；目标固定为裸形时不要改成未分配的 `たがっている`。

“可观察”不要求每张卡都逐字写出「と言う」或设置固定数量的行为证据；但场景和句子合起来必须让读者能指出愿望从哪里看出来。只有抽象的“他心里想……”而没有言语、反复行为、拒绝或选择等线索时，应换场景或列为未决。

否定形是“不愿意／不想表现出该愿望”，不是“不能、禁止、没做过”。`分かりたがる` 需要真实的“想弄明白”对象和行为依据，不能把 `知りたがる` 的自然度直接借过来；`思いたがる` 要能读成“想把某事认为……”而非泛泛思考。`いる` 要写主动停留、留下或陪伴，`来る` 要有移动参照点。

## `ようとする`：尝试和临界状态

肯定可表达主体尝试／准备实施动作，也可表达无意志事件即将发生。每张卡选择一条清楚路线：

- 尝试义不保证完成，也不自动表示失败；只有句中有受阻后项时才译出“没能”。否定通常是“不肯／不作尝试”，不是“没做成”或“不能做”。
- 临界状态可写「落ちようとする」等物体正要发生的变化，不拟人化为“物体想掉下去”；译文使用“正要／眼看要”。本批未分配的否定形式不能自行补写自然现象的“不肯发生”。
- 裸形与 `ようとしている` 的差别按当前句的时体和课程分配判断：裸形可作修饰语、叙述习惯或临界状态；不要因为词典例句常见进行体就擅自改目标形式，也不要只因没有进行体就否定自然的裸形。译文须明确是“试图／正要／眼看要”中的哪一种。
- `思おうとする` 是试着形成某个判断，不能替换成「～しようと思う」；`来ようとする` 不等于已到达，`いようとする` 必须有地点、陪伴或停留时段。

## 请求、命令、许可和邀请

命令形、`なさい`、`てください`、`ないでください`、辞书形＋`な` 的强度和关系不同。每句应有可信的说话人／听话人关系或引用场景；不要把强命令全部写成无背景的“请……”，也不要把 `なさい` 当成礼貌请求。

`てもいい` 是许可，`なくてもいい` 是“不做原动作也可以”。尤其 `忘れなくてもいい` 表示“不必忘掉／可以记着”，不能译成“无需记住”（这会把方向翻反）。译文准确保留否定范围即可，无需同时补出日语没有的正向结论。`ませんか` 要是真正的邀请或提议，不是把普通否定疑问机械套在每个动词上；对象、共同参与者和时间背景应能支持邀请。仅在中文加“要不要一起”或日语加「一緒に」，不能把「分かりませんか」的确认理解自动变成邀请。

审核需区分“固定形式不成立”和“当前用例不合适”。非意志或认知动词在限定对白中可能出现否定请求或禁止；若采用这种用法，核实完整上下文的说话关系与实际意义，并在短场景或答后说明中保留限制。不能用「分かったふりをしないで」等另一目标替代分配的「分からないでください」。资料支持构式或实际使用，不自动批准原创整句。

## 义务表达：保留原动作方向

`なければならない`、`なくてはいけない`、`ないといけない` 都是“必须使原动作或状态成立”。否定形在这里属于构式的一部分，不得把原词义的方向再翻转：

- `忘れないといけない` 是“必须忘掉”，不是“不必忘记”；
- `分からなくてはいけない` 是“必须理解／必须弄明白”，不是“必须不懂”；
- `いないといけない` 是“必须在场／必须待在某处”，不是“不能在场”；
- `思わないといけない` 仍是“必须认为／必须这样想”，须有具体命题和劝告语境。

`忘れる`、`分かる`、`思う` 等心理或状态词不是整族禁用；逐句判断动作方向、控制性和角色关系。没有自然语境时保留具体未决项，不能换成别词或降低审核标准来填数量。

`分からなければならない` 等句子还要确认“谁必须理解什么”：用人物、职责或任务场景明确主体，用「が」或自然的范围表达明确内容，避免让读者只读成“题目／说明本身容易理解”。`てほしい` 用无意志变化（如 `壊れてほしい`）时，执行者可以不出现，但场景仍应让说话人的愿望和承受变化的对象清楚；不能把省略施事误读为“希望某人把它弄坏”。`思いたい` 至少要有可判断的命题或对象，优先使用「〜と（思う）」等补语，不用空泛的“想想看”。

## 读音候选的人工处理

本阶段试稿表明，词典差异可能来自合法异读、连浊和分词边界，不能自动改写正文或读音。常见候选包括「私」的 `わたし／わたくし`、「日本」的 `にほん／にっぽん`、「故郷」的 `ふるさと／こきょう`、「母」在称谓中的 `かあ`、「皆」的 `みんな`，以及「誕生日」的连浊。`箱` 也可能被分词器误析为连浊的 `ばこ`；应按完整词义、句中读法和实际 ruby 判断。作者改写正文后必须同步重跑结构检查和词典候选，报告区分确定错误、合法异读和工具误判。
