# 本地化覆盖与英语审核

本文件用于用法卡的英语或其他语言本地化。它只管理学习者可见的本地化字段。日语正文、读音、目标形式、词义身份和自然度审核仍由 canonical 卡片管理。

## 1. 固定身份与覆盖层

先从最终运行时 `USAGE_CARDS` 冻结本次在用卡清单。不要从历史草稿、审核票、暂缓清单或源文件行数推算范围。冻结记录至少包含当前提交、卡片 `id`、`senseId`、`form`、词类、课程阶段和 canonical 卡片对象的 `sourceHash`。

卡片 `id` 是跨语言稳定身份。语言、文件名和数组位置都不能进入 ID。`sourceHash` 使用项目约定的 canonical 序列化和 SHA-256；同一任务内只使用一种序列化方法。哈希必须覆盖会改变本地化含义的最终运行时字段，包括日语句段、reading、scene、translation、note、senseId 和 form。

本地化内容放在独立覆盖层中，不修改 canonical 卡片。英语条目使用以下最小结构：

```js
{
  id: 'usage:negative',
  sourceHash: 'sha256:…',
  scene: 'The speaker decides not to drink tonight.',
  translation: 'I will not drink alcohol tonight.',
  note: 'Optional short usage note.'
}
```

`note` 仅在源卡确有说明或英语学习者需要短说明时存在。覆盖层不得改写 `senseId`、`form`、日语 `before`、`after`、reading、target、适用性、审核状态或课程归属。不得把英语文字回填到 canonical 卡片的中文字段。

canonical 卡片内容变化后，旧 `sourceHash` 不匹配。该本地化条目和它的审核结论立即过期。作者必须根据新卡重新翻译。协调者不得只更新哈希来保留旧文案或旧审核票。

源卡有 `note` 时必须同步提交该说明的英语版本，不能只翻译场景和整句。冻结中英合并稿前，除通用覆盖检查外，还运行项目的 `validateEnglishUsageAgentOverlay` 严格字段校验，提前核对源卡与覆盖层的说明字段是否对应；字段缺失不能靠自然度批准票放行。

## 2. 编写英语内容

英语 `scene` 说明具体人物、对象或处境。它须帮助学习者理解日语句子的使用场合。场景可以用英语说明相关动作或状态；这正是场景的用途，不算泄露日语答案。场景不得直接写出日语挖空目标、目标读音、完整日语答案或变形步骤，也不得把答案伪装成提示。

英语 `translation` 只翻译完整日语句实际表达的内容。它须保留人物角色、时态、肯否、否定范围、完成度、授受方向和语体。不要从中文场景补入日语没有表达的信息。中文原字段是参考，不是英语内容的唯一来源；作者必须同时阅读完整日语句和目标形式。

英语 `note` 保持简短。它只解释实际需要的视角、语用或歧义。它不能用来补救不自然的日语句，也不能替代课程说明。

每个作者批次最多 64 张。批次使用冻结清单中的连续稳定范围，并保存 batch ID、卡片 ID、源哈希、作者身份和交付收据。批次之间不得重叠。所有批次与未分派集合的并集必须等于冻结范围。

## 3. 全量机械检查

机械检查覆盖每张最终在用卡。检查必须证明：

- 覆盖层 ID 集合与冻结的在用卡 ID 集合完全相同。
- 每个 ID 恰好出现一次，没有缺失、重复或额外条目。
- 每个 `sourceHash` 与当前 canonical 卡片一致。
- `scene` 和 `translation` 非空，`note` 如存在也非空。
- 英语字段没有未允许的中文残留、占位符、损坏的插值或答案泄漏。
- 日语正文、reading、target、形式、适用性和自然度记录没有因本地化而变化。

机械检查通过不代表英语自然。它只证明范围、结构和绑定关系正确。

## 4. 确定性抽样审核

从冻结清单生成可重复的审核样本。相同清单必须得到相同样本。样本是以下集合的并集，并按卡片 ID 去重：

1. 每个有效“目标形式 × 词类”组合至少一张。按卡片 ID 排序后选第一张。
2. 每个作者批次至少一张。按卡片 ID 排序后选第一张。
3. 所有带 `note` 的本地化条目。
4. 对尚未入样本的卡片按稳定卡片 ID 哈希排序，抽取 5%。数量向上取整。

最终样本必须覆盖全部课程和六个课程阶段。若上述规则没有覆盖某门课程或阶段，按卡片 ID 排序后补入该范围的第一张。报告保存抽样算法版本、冻结清单哈希和最终样本 ID，不能人工替换难审卡片。

独立审核者逐张读取完整日语句、目标形式和英语字段。审核者检查英语自然度、原词义、人物角色、时态、否定范围、语体、场景一致性及答案泄漏。审核者按 ID 和 `sourceHash` 记录结论与具体理由。

任一样本失败时，先把该卡退回修订，再把它所属的整个作者批次加入扩查范围。扩查覆盖该批次全部卡片，不再抽样。若失败来自可复用模板或共同翻译规则，协调者还须扩查所有受同一模板影响的批次。修订改变内容后，旧审核结论失效；审核者重新检查修订卡及受影响范围。

只有全量机械检查通过、抽样报告完整、扩查问题清零时，英语覆盖层才可接入。未通过的条目不能回退中文，也不能通过隐藏题目来制造完整覆盖。

## 5. 交付与维护

交付报告写明冻结卡片数、覆盖条目数、批次数、样本数、扩查范围、修订数、当前哈希匹配结果和未解决问题。分清“已翻译”“机械检查通过”“语言审核通过”“已接入”和“已发布”。

新增、修订、恢复或暂缓 canonical 卡片时，协调者重新计算最终在用清单。新增和修订卡须生成新的本地化条目。退出在用范围的卡片须从发布覆盖层移除，但历史本地化和审核收据可以保留为证据。

本地化审核不批准或否定日语自然度。审核者若发现日语源卡问题，应按 canonical 卡片流程单独重开自然度审核，并暂停该条目的本地化接入。
