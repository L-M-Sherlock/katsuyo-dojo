# 可能与态：角色与否定范围

先为每个词确定一个自然用法，再写各个分配形式。审稿时先把完整日语还原成“谁做什么”，对照短场景与中文；同一背景下肯定和否定的角色不能交换。角色分析写入交付报告，供复核使用，不添加到学习者卡片里。

## 四类检查

- **可能**：交代技能、身体条件、设施或安排带来的可行性，不当作推测概率。「遅れられる」只能在有晚到余地或许可等适当语境下使用，不能译成“可能会迟到”；其过去形不表示“避免了迟到”，否定也不等于“肯定不会迟到”。过去可能可描述实际获得的能力或当时条件，不必一律写反事实「のに」。
- **受身**：明确受到动作或事件影响的人／物。自动词间接受身需要适当的受影响者及具体影响，不能只给事件套「被」。否定事件后不要仍断言其伤害已经发生。与可能、尊敬同形的「られる」必须由句子和场景确立受身用义。
- **使役**：区分使役者、动作执行者与宾语；非意志变化可以表达原因引发的结果，但不能随便找“实验装置”来包装生硬搭配。否定不擅自增添禁止、阻止成功或能力不足的含义。
- **使役受身**：受影响的一方作主语，通常就是动作执行者；表示某项活动被终止等事件时，活动本身也可作主语，需单独核实这种用法。使役者通常用「に」。肯否变化后保持这一关系；「私は部長に…来させられない」和「部長は私を…来させられない」不同，后者容易变成使役可能，而非“我没被要求来”。没有被迫做不证明该动作没有发生。

使役受身的否定译文使用“不会／没有被要求或被迫做”，不机械加成“不能／没能被迫做”。曾有交叉审稿将一批正确的受身否定改成能力否定，审稿建议本身也必须对照课程形式和实际句法复核。

## 不要用相邻词义或额外结构过关

核对固定词条是否在句中仍是同一用法，不能把自动词「変わる」当他动词「変える」直接带「予定を」。字典存在自他两用时，应核对当前词义，不凭表面词尾断定。主语、助词或一个省略成分即可改变解释，不能靠中文翻译补救日语。

涉及「来る」时，场景和句子要建立来向基点，例如叙述者所在的办公室、家或会场；不能只把“去参加会议”翻成“来”，再靠中文补救。

完整目标由活用器插入。例如要求受身普通形时，可构造「…【泣かれる】と眠れない」，不能在槽后再写「泣かれて」造成目标重复。直接练「いる」时，不应在槽前加「待って」而把实际用法换成「待っている」的派生。

清单允许构形不等于句子已经通过语言审核。「落ちさせる」等比对应他动词少见的形式，要核实完整用例的用义与自然度；确实找不到适合场景时，交出明确未解决的词义／形式、尝试与原因，由主代理处理，不改变词池，不藏入 approved。

查《基本動詞ハンドブック》时必须读**当前义项的文法栏**，不能只看词头自动列出的活用表；同形词的另一义项、他动词用法、尊敬或可能用法不能替当前题背书。课程许可改变后重导清单，保持被暂缓的组合及原因可查，不把“本课未采纳”写成“任何语境都不成立”。

「勝たされる」可用于对手故意让自己获胜，不等于教练命令自己就取得胜利；「信じさせられる」可说明受到说法或资料诱导而相信，不等于仅被口头要求相信。这类外界影响需逐句确立，否定不推论实际输赢或个人是否独立相信。另一方面，不能把该说明泛化到所有感情词；JF BMA00037 明确对「楽しむ」的使役受身作了教学限制。

## 交付前

1. 在报告中逐词标明主体、动作执行者、受影响者／宾语与肯否范围，并逐条确认实际生成句。
2. 检查「に／を／が」和主客角色，尤其否定形式是否退回了另一种句法解释。
3. 核对源词读音与派生读音；词典把「来させる」或「出させる」分成别的用法时，回到题目指定词义判断。
4. 运行结构与读音对照；逐句审阅最后输出，不能只报告 `issues: []`。修订正文必须同步读音和译文。

角色复杂的批量稿先试作再扩充。同一词可以复用已经核准的人物背景，再逐形写清肯否时态，不必为每个形式随机更换演员或编造疾病、设备故障。终审保留实际卡片 ID、修订前后完整句和文件指纹；后续改动过的句段必须重新检查，不能沿用旧报告的“已通过”。

查看 `translation` 的实际值，不能把日语原句重复放进去。逐句中文翻译只表达日语本身，场景交代的背景不自动进入译文。对于能力过去，「教えられた／学べた」不自动证明对方已经学会，不能将教学结果无条件写入译文。
