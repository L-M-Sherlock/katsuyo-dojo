# 常见多步组合

「多步活用组合」现在包含四类整体应用。原 `compound.multi-step` 的 ID 和分数保留，显示名称明确为「受身・愿望・否定过去的组合应用」；它不代表所有多步组合都已掌握。

| 题型 | 正确路径 | 应用知识点 |
|---|---|---|
| 受身・愿望・否定过去（原有） | 叱る → 叱られる → 叱られたい → 叱られたくなかった | compound.multi-step |
| 尝试・愿望・过去 | 読む → 読んでみる → 読んでみたい → 読んでみたかった | compound.chain.temiru-desire-past |
| 受身・进行／状态・过去 | 書く → 書かれる → 書かれている → 書かれていた | compound.chain.passive-progressive-past |
| 使役・接受允许・过去 | 行く → 行かせる → 行かせてもらう → 行かせてもらった | compound.chain.causative-receive-past |

新增题型由 `multi-step-forms.mjs` 声明首段与后续表达，再复用现有构形、可接受变体、基本操作和拆步逻辑。解析展示三个阶段，形容词式和动词式结尾继续使用原有共享规则。每类有独立应用指标；辅助作答不能更新该指标，正确中间形式会避免重复检查，无法唯一归因的输入继续拆步。

题库使用人工限定的适用词条：尝试及请求允许使用可主动实施的动作，受身状态使用相应及物动词。扩充词条前应核对搭配；不能机械地把所有词套入每种链。

接受已有规则允许的缩约，例如「書かれてた」「行かしてもらった」。整题可接受多条合法路径，但给定长使役中间形式后，只检查与该中间形式兼容的后续变化。

新增三个应用指标初始未掌握，不从原有多步指标复制成绩。已有知识点、历史记录和此前的应用分数保持原状。
