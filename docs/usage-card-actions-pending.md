# 动作与状态：待裁定配对

当前保留 66 个精确词义／形式配对未决；它们没有接入用法卡。开放课程规则已用于本轮重审：旧教材未列出某种用法不构成拒收理由，但每张卡仍须有自然完整句、明确词义和可靠否定／方向范围。此清单不宣称相应日语形式在所有语境都不成立。

## 1. verb:持つ:もつ/aspect-2/02

- 原句：旅行中に困らないよう、予備の現金を持ってある。
- 场景：为旅行遇到意外，事先备有应急现金。
- 译文：为免旅行途中为难，已经事先备有应急现金。
- 审核理由：现金持有义保留，但「予備の現金を持ってある」仍难确认为自然的既成准备状态表达；旅行用途说明备钱目的，却没有化解持つ本身在这里的持续持有读法。考虑改为持有备用账户或资格同样未得到更稳妥搭配；持っている／用意してある各改变固定形式或原词，不能代换。保留具体搭配未决，不断言持つ全词不可接てある。

## 3. verb:待つ:まつ/aspect-4/00

- 译文：服药后已经等了至少三十分钟，请开始检查吧。
- 审核理由：服药后三十分钟是明确有界等待，检查是合理后续用途，故不能因为动作没有可见物理结果就否定本句；然而「三十分は待ってある」仍不如等待经过的普通完成表达稳妥，本轮未取得可比的可靠用例，无法批准其搭配。三十分は可表达至少等了三十分，译文保留该范围。

- 译文：我在车站等着，但朋友仍然没有朝这边来。
- 审核理由：まだ／こちらへ与车站等待构成普通尚未来到；「来てこない」多出的くる没有可区分的趋近或发展意义。尝试要求先到一处再回来仍难维持来る的同一说话视点，不能靠中文没有来批准。

## 66. verb:来る:くる/direction-2/18

- 原句：昨日は閉店まで待ったが、配達員は店に来てこなかった。
- 场景：昨天在店里一直等到关门，送货员也没来。
- 译文：昨天一直等到关门，送货员也没有来店里。
- 审核理由：昨天等到闭店与送货员不来是自然背景，问题在「店に来てこなかった」的双重趋近；过去否定并未修复该组合，译文也只译单纯没来。考虑来访后返回的双程场景仍未找到明确自然句。
