# 本次反馈处理后的日语句清单

只列变形与日语句；暂缓项保留源句，其余列本次核验后的句子。

## 暂缓（7）

| 变形 | 日语原句 |
| --- | --- |
| 読む→読んでない | 発表が近いのに、資料を読んでない。 |
| 食べる→食べてない | 夜勤が始まるのに、夕食をまだ食べてない。 |
| 読む→読んでなかった | 稽古が始まった時点では、台本を読んでなかった。 |
| 食べる→食べてなかった | 遠足の前に朝食を食べてなかったので、途中でおなかがすいた。 |
| 勝つ→勝ってもらわなかった | あの練習試合では、助っ人には勝ってもらわなかった。自分で戦った。 |
| 届く→届いていかない | 会合を重ねても、地域からの声は本庁まで届いていかない。 |
| 足りる→足りてこなかった | 新人が入って、あのころは人手も足りてこなかった？ |

## 微调后（8）
