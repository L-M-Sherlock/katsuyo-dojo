# 独立作答、辅助练习与复测

原题答错后，拆步答对说明学习者能在给定前提下完成局部操作，不能直接证明能独立选择并完成整条变化。因此，题目结果、知识点证据和待复测任务分别记录，并在同一次保存中提交。

## 计分口径

| 作答条件 | 独立掌握记录 `byKc` | 辅助记录 `assessment.assistedByKc` | 待复测 |
|---|---|---|---|
| 无帮助的独立整题答对 | 记录本题规则；活用题不顺带给原词分类、分类启发式加正确分 | 不变 | 已有任务须满足复测条件才能解除 |
| 独立整题答错且有可靠归因 | 只更新可确定的错误与可确认的局部规则 | 不变 | 保留目标形式与操作路径 |
| 独立整题答错但错因不唯一 | 不凭焦点猜测错误原子 | 不变 | 仍保留整题失败，安排复测 |
| 拆步、给定中间式、词类或规则后作答 | 不变 | 仅记录实际检查的局部规则 | 不解除 |
| 原题使用提示、语法反馈后重试 | 不变 | 仅记录可评估的局部规则 | 不解除 |
| 同词或间隔不足的再次作答 | 不变 | 记录为练习；不冒充独立复测 | 正确也不解除；真实错误保留 |
| 查看答案 | 不变，不把焦点知识点自动记错 | 不补造正确或错误原子 | 安排独立复测 |
| 单纯原词笔误或无效输入 | 不变，不增加题数 | 不变 | 不创建或解除任务 |

展开提示时立即保存帮助条件与待复测，不能等到提交才记录；刷新也不会洗掉提示影响。尚未作答时，不增加任何题数或失败次数。

单纯提醒核对原词、没有透露活用规则或答案的笔误重输，仍可完成一次独立语法作答。原题每日题数、正确数和连对只按原题计一次；拆步不增加它们。原题使用帮助后的“答对”不增加失败次数，仍保留为当次题目结果，但界面和日志明确其辅助条件，不能推动独立达标。

辅助记录不包括原词分类、分类启发式、词汇覆盖、整体应用或复合形式覆盖。重复诊断同一知识点时，已有步骤评估范围与事件幂等机制防止重复加分。`assessment.independentByKc` 只保留可知来源的独立证据，`byKc` 还可能包含保留下来的历史基线。

## 先检查哪里

“可疑”表示优先补查某一阶段，不等于已经确定某个知识点错误。完整输入能对应同一表达的另一后续形式时，可以缩小检查范围，例如：

- 要求「乗る → ている・否定形」，却写成「のっていた」：先检查「乗っている → 乗っていない」，不重复从原词构造「ている」。这一步的成功只记辅助练习。
- 要求否定过去，输入已经是完整的否定形：保留否定中间式，只检查过去变化。
- 词根损坏、跨表达同形或多个阶段解释都成立：保持保守，继续有限拆步，不据此给前段或整条应用加独立成绩。

路由按形态结构与合法变体匹配，不使用编辑距离推测认知原因。20 类接续与态家族的过去、否定、否定过去，以及多步受身愿望组合共 61 个目标使用这一规则；基本礼貌变化等已有可靠直接归因的情形保留直接归因。范围和保护用例见 [阶段优先补查](probe-routing.md)。

## 复测条件与调度

复测要求 **相同目标形式、相同实际操作路径、避开原失败词和最近受助或练习过的词、无帮助**，并且距最近一次该目标的原题或辅助操作，至少完成两道其他整题。例如原题失败为第 1 题，第 2、3 题练其他目标，第 4 题才可复测。拆步、刷新、跨日和日志裁剪不会凭空增加间隔。过早重练会重新计算间隔。

「乗る」换成「取る／待つ」能保持促音便路径；换成「書く」涉及不同音便，不能据此解除前一个任务。其他时态也不能替代原目标。目标键保存完整规则签名并校验，不能只凭课程名或词尾匹配。

当同规则题库只有两个词且分别是失败词、最近受助词时，不能把受助词直接当作换词复测。调度会明确安排一次不计独立成绩的巩固题，再间隔两道其他整题，之后使用不同的词复测，避免有限词库永久卡住。

按完整题库判断，如果同规则目标确实只有一个词，则改用至少 **24 小时以后、同时满足两题间隔**的同词复测。页面明确显示这一限制。筛选专项或排除最近词条不算“词库只有一个词”。

每次新题优先安排已到期复测。尚未到期时，围绕最早等待的目标安排其他目标作为间隔题；不会把所有待复测目标一起排除而造成死锁。专项优先保留本课范围，缺少间隔题时可使用已解锁基础分类，页面显示实际练习课程。单词限制需要等待时，仍允许学习其他内容。

待复测影响相应课程和整条路线的完成状态，不把所有同题出现的基础知识点都降成未掌握。拆步完成、跳过或答对辅助题均不能解除任务。

## 保存与历史迁移

Profile v7 使用独立存储键 `katsuyo-practice-profile-v7`；导出格式为 5，日志为 2，兼容旧导出格式。独立成绩、辅助记录、待复测和日志一起保存；多标签冲突全不提交，写入失败仍可导出当前内存快照。旧页面不会覆盖新版评估状态。

旧数据只依据可验证的连续日志修正辅助加分。原始事件不改写，修正另记迁移事件。没有日志或快照断链的历史统计保留并标明来源不完整，不补造独立成功或失败。再次导入新版数据使用其权威评估状态，不重放旧失败而恢复已解除的任务。详见 [迁移规则](assessment-migration.md) 和 [作答日志](practice-log.md)。

## 验证范围

独立 subagent 冻结的输入与预期、复核理由和实际测试分别记录在 [学习证据验收](learning-evidence-audit.md) 与 [复测调度验收](independent-retest-audit.md)。测试调用真实计分、状态、迁移和页面入口；全量输入审计另外检查归因、阶段路由、有限拆步与计分隔离。正确/混合学习模拟使用相同的证据计分器验证知识路线可完成，持久化复测则由状态和页面测试覆盖。

这是一套可执行的评估策略，不声称任意输入都能唯一反推出学习者的心理原因。无法确定的原子不扣分，同时用待复测保留尚未独立证明的整题能力。
