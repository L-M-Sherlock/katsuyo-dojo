# 小候选池的自然例词增补

本次扩充常用、能放进日常语境的词例，优先解决四个非不规则词造成的小候选池。没有修改达标门槛、两道其他整题的复测间隔或选题排序。

## 候选池变化

| 完整变化路径 | 扩词前 | 扩词后 | 增补词 |
| --- | ---: | ---: | --- |
| 受身＋愿望＋否定过去，う尾 | 3 | 13 | 誘う、雇う、扱う、疑う、嫌う、からかう、祝う、追う、笑う、思う |
| 尝试＋愿望＋过去，ぐ尾 | 1 | 4 | 脱ぐ、稼ぐ、注ぐ |
| 尝试＋愿望＋过去，す尾 | 2 | 6 | 探す、直す、出す、押す |
| 受身＋进行／状态＋过去，う尾 | 2 | 7 | 洗う、払う、扱う、疑う、雇う |

另为「知る」「読む」加入受身＋愿望＋否定过去的日常语境。全部增补必须匹配旧的 `assessmentTarget` 规则签名，是真正的换词复测；换一个语境仍是同一个词。

## 新增八词

下列完整例句为本次审核自拟，不是词典引文。中文题干只显示人物关系或场景，不显示这些日语例句，也不替学生决定时态和肯否。

| 词条与本次词义 | 审核例句 |
| --- | --- |
| 誘う・さそう・邀请 | その日は休みたかったので、飲み会に誘われたくなかった。 |
| 雇う・やとう・雇用 | 労働条件が合わず、その会社には雇われたくなかった。 |
| 扱う・あつかう・对待 | 子供のように扱われたくなかった。 |
| 疑う・うたがう・怀疑 | 友達に嘘をついたと疑われたくなかった。 |
| 嫌う・きらう・讨厌 | 本音を言って、友達に嫌われたくなかった。 |
| からかう・からかう・取笑 | 新しい髪型を、クラスの人にからかわれたくなかった。 |
| 祝う・いわう・庆祝 | 誕生日を大げさに祝われたくなかった。 |
| 追う・おう・追赶 | 鬼ごっこでは、足の速い子に追われたくなかった。 |

选词参考基础词汇地位和当前词义的日常用法，没有声称按某一语料库词频排序。国立国语研究所 IPAL 提供按词义区分的词类、参与者和活用用法，例如 [誘う](https://www2.ninjal.ac.jp/dictionaries/IPALBV/pdf_dir/さそう.pdf)、[雇う](https://www2.ninjal.ac.jp/dictionaries/IPALBV/pdf_dir/やとう.pdf)、[疑う](https://www2.ninjal.ac.jp/dictionaries/IPALBV/pdf_dir/うたがう.pdf)、[嫌う](https://www2.ninjal.ac.jp/dictionaries/IPALBV/pdf_dir/きらう.pdf)、[祝う](https://www2.ninjal.ac.jp/dictionaries/IPALBV/pdf_dir/いわう.pdf)、[追う](https://www2.ninjal.ac.jp/dictionaries/IPALBV/pdf_dir/おう1.pdf)。[扱う的词义](https://www2.ninjal.ac.jp/basicverbbank/single_headwords/あつかう-扱う.html)取“对待”，不借“操作机器”的词义扩大题型；[からかう](https://kotobank.jp/word/からかう-467246)取拿别人开玩笑的意思。

## 适用边界

新增词只开放已审过的分类、基础活用、受身及指定完整组合。其余表达暂不出题，完整构形仍可识别。例如「嫌われたくなかった」自然，不能据此把「嫌おう」「嫌ってみる」等当成普通日常练习。

已有词的新增语境强调真正受到影响的人，例如私人日记的主人不愿日记被别人阅读，所以「読まれたくなかった」不需要让日记拥有愿望。笑う保留“笑”的词义，用同学发笑对当事人的影响说明间接受身；不会悄悄修改旧词条释义。

尝试组合的新增词只扩充 `temiruDesirePast`；不因此扩大共享基础动作词单的使役授受组合。「雇われていた」允许雇佣关系持续的状态义，不只限于“正在雇用”的过程。

## 稳定性检查

新增的 `tests/natural-word-supply.test.mjs` 对扩词前目录另存快照，验证原有 16,583 题及 671 条语境不变，只允许清单中的已有词新增组合；原来的知识点、课程归属、覆盖要求、规则签名、历史分数和复测锚点均须保留。最初的 `eligibility-baseline.json` 保持冻结。

```sh
node --test tests/natural-word-supply.test.mjs
npm run audit:eligibility
npm run simulate:perfect
npm run simulate:mixed
```

本轮验证结果：743 项测试全部通过；知识模型与目录审核、TypeScript、ESLint、生产构建通过。全对统一路线仍用 608 道原题完成 119 个达标知识点与 89 个覆盖项；混合作答模拟用 1614 道原题完成。实际题库增加 200 题，达到 16,783 题；多步组合从 111 题、50 词扩大到 135 题、69 词。以上为发布前的本地验证结果。
