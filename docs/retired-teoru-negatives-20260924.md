# 从课程移除「ておらない／ておらなかった」

2026-09-24，用户明确要求将 `teoruNegative`、`teoruNegativePast` 两个形式整族移出项目的教学与出题范围。课程仍保留 `teoru`（ておる）、`teoruPast`（ておった）和 `toru`（口语缩约）。本次没有把「ておりません」或「ておらん」作为新课程形式接入；新增表达需要另行确定用义与例句。

移除发生在复合形式定义处，因而课程形式、标签、诊断目标、完整词形识别和常规题池不再列出这两个形式。活用函数收到这两个已退役的旧 ID 时明确报错，避免落入默认构形分支生成误导性词形。历史卡片、审核票与作答记录仍留在原始数据和证明中；在用卡目录过滤这两种形式。旧错误待复测目标若因此没有对应题目，按现有机制暂停并保留，不算作已掌握。

移除前的本地在用题库中，这两个形式共有 283 张卡（`teoruNegative` 141、`teoruNegativePast` 142）；完整自然度证明的历史清单另有 9 张此前已被[用户指定暂缓](usage-card-user-directed-deferrals-20260924.md)，合计 292 张旧卡。旧版自然度审核证明和已发布内容账本均不回写。此前的内容批准不再构成这两个形式重新入题的许可。
