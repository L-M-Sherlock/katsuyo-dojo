# 自由挑战

顶部和课程栏的「自由挑战」入口对新档案立即可用。点击后进入独立的 `#/challenge` 页面，顶部菜单突出「自由挑战」。页面提供「挑战最高难度」，也可以从全部 43 门课程中勾选一门或多门，包括尚未解锁的课程和形容词课程。选课卡片沿用网站的纸色、边框与强调色，支持搜索、动词/形容词筛选、全选当前结果和清空。筛选不会丢失已选课程。

## 选题

挑战使用所选课程的已审核题库，绕过先修与课程解锁筛选，保留词义、语境和构形适用性限制。每轮最多 12 道原题，先在所选课程间均衡轮换，再轮换课程内的目标形式和实际词类，并优先更换词条。某课题池耗尽时让出题位给其他所选课程；全部题池耗尽才提前结束，不重复相同题目凑轮次。所选课程超过 12 门时，后续轮次继续轮换，避免一直只练前面的课程。

开始作答进入 `#/challenge/play`，顶部菜单仍突出「自由挑战」。挑战作答使用居中的单栏布局，不显示常规课程侧栏、专项筛选或进度卡片；更换课程和返回自适应仍可在题目上方操作，知识进度可从统计页查看。选择课程后不会在本轮中自动降到基础课程，也不会跳出所选课程范围。答错仍可进行本题的诊断拆步，也可以跳过拆步继续挑战。已掌握的课程同样可挑战；本轮完成后可以继续当前选课组合、更换课程或返回自适应训练。

## 学习记录

挑战与自适应训练共用评分、诊断、统计和作答日志，记录归属实际作答课程。独立正确作答积累本题可观察的规则证据；词类必须由分类题确认，不能从高级活用正确直接补算词类。提示、揭晓和拆步仍按辅助练习处理；独立复测继续遵循原有题数和换词条件，不绕过评估规则。

点击入口或选择课程本身不会修改知识点分数、已引入知识点或常规课程访问权限，也不会替换原有自适应学习目标。未测到的内容仍未确认。挑战中已达标但尚未常规解锁的规则会显示为「已达标 · 待解锁」，知识点总数与统计页使用一致的实际掌握记录。

返回自适应训练后，原路线会依据已积累的证据继续安排练习。

## 状态与验证

浏览器通过 v2 偏好键保存当前课程集合，刷新后继续同一组合，并兼容原 v1 单选记录。返回常规训练、重置或导入进度时退出挑战。该模式偏好不写入 Profile；知识点成绩、日志和统计仍随原有 JSON 备份保存。

在选课页暂停练习计时并隔离原题快捷键，返回当前练习/挑战保留输入和拆步状态。进入统计页后返回也会恢复正确的挑战路由和菜单状态。浏览器前进、后退和直接打开链接保持页面与菜单一致；无可恢复挑战时，作答链接回到选课页。页面适配笔记本及手机，开始按钮和已选数量在短屏上保持可见。

测试覆盖新档案直接进入最高课程、跨解锁选课、答对和答错后的课程保持、真实证据写入、退出/刷新、所有课程的非空题池、轮内不重复、目标轮换和小题池结束行为。

多选测试额外覆盖课程公平轮换、题池耗尽时再分配、43 门课程跨轮覆盖、逐题课程统计归属、多选恢复、旧偏好迁移及页面导航状态。
