# 自由挑战

顶部和课程栏的「自由挑战」入口对新档案立即可用。弹窗提供「挑战最高难度」，直接进入「多种表达的组合活用」；也可以从全部 43 门课程中自选，包括尚未解锁的课程和形容词课程。

## 选题

挑战使用所选课程的已审核题库，绕过先修与课程解锁筛选，保留词义、语境和构形适用性限制。每轮最多 12 道原题，在课程内轮换不同目标形式和实际词类，并优先更换词条。题库较小时提前结束，不为了凑满轮次重复相同题目。

选择课程后不会在本轮中自动降到基础课程。答错仍可进行本题的诊断拆步，也可以跳过拆步继续挑战。已掌握的课程同样可挑战；本轮完成后可以继续本课、更换课程或返回自适应训练。

## 学习记录

挑战与自适应训练共用评分、诊断、统计和作答日志，记录归属实际作答课程。独立正确作答积累本题可观察的规则证据；词类必须由分类题确认，不能从高级活用正确直接补算词类。提示、揭晓和拆步仍按辅助练习处理；独立复测继续遵循原有题数和换词条件，不绕过评估规则。

点击入口或选择课程本身不会修改知识点分数、已引入知识点或常规课程访问权限，也不会替换原有自适应学习目标。未测到的内容仍未确认。挑战中已达标但尚未常规解锁的规则会显示为「已达标 · 待解锁」，知识点总数与统计页使用一致的实际掌握记录。

返回自适应训练后，原路线会依据已积累的证据继续安排练习。

## 状态与验证

浏览器单独记住当前挑战课程，刷新后继续挑战该课。返回常规训练、重置或导入进度时退出挑战。该模式偏好不写入 Profile；知识点成绩、日志和统计仍随原有 JSON 备份保存。

打开选择弹窗时暂停练习计时并隔离原题快捷键，关闭后保留输入和拆步状态。弹窗支持 Escape 和 Tab 焦点循环，适配笔记本及手机宽度。

测试覆盖新档案直接进入最高课程、跨解锁选课、答对和答错后的课程保持、真实证据写入、退出/刷新、所有课程的非空题池、轮内不重复、目标轮换和小题池结束行为。
