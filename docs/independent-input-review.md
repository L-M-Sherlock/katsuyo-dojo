# 独立错误输入复核（2026-09-08）

三个 subagent 分别从原生动词、形容词、复合表达与拆步场景设计输入。先保存语法预期，再运行分析器，没有从现有错误候选反推种子预期。主线程复核分歧、修复确认的问题，将原始种子、复核理由和回归测试一起保留。

## 独立样本与边界

| 组别 | 固定种子 | 范围 |
|---|---:|---|
| 原生动词 | 117 | 九种五段词尾、一段、する／来る、行く，基本变化及可能与态 |
| 形容词 | 137 | い／な、いい例外、基本接续、条件、副词、たい／てほしい后续 |
| 复合表达与拆步 | 94 | 派生尾词类、缩约、授受、否定过去、受身愿望多步、固定前部损坏 |
| 汉字写法对照 | 96 | 形容词种子的等价书写，不计作新错误模式 |

348 个独立种子涉及 67 个目标形式，其中 245 个错误答案、86 个正确答案、17 个疑似词汇笔误。另有 96 个写法对照。它们寻找原生成器的盲点，不能代替覆盖全部 131 种形式的生成审计。

4 个原生「ある」种子是特意加入的词库外扩展探针。当前网站不出这个原词，底层通用活用器对此仍有错误：将「あらない」视为普通五段结果。原始期望没有删除或改成通过，复核文件明确标为 `engine-extension`，不计入通过的 440 个网站范围输入。若把「ある」加入词库，必须先解决这些探针。当前已有的「てある」后续单独测试，相关归因已修复。

## 找到并修复的问题

| 输入示例 | 修复后的行为 |
|---|---|
| 見る命令形：みよ；食べる：食べよ | 接受标准命令变体，默认展示仍为ろ形 |
| する可能形：出来る；高い过去形：ﾀｶｶｯﾀ | 接受对应汉字、片假名书写；不忽略促音、长音和词根差异 |
| 高い条件形：たかくれば | 直接定位い形容词条件接续 |
| 静か：しずかだない／しずかだて／しずかの／しずかだば | 按实际目标定位对应な形容词接续，无需重复同一答案做拆步 |
| 書く受身：かかられる；使役：かかさせる | 保留已形成的ア段边界，定位误接的受身／使役后缀 |
| 食べる：たべよお／たべろう | 定位意向／命令接续误写 |
| 話すて形：はなすて；読む→ている：よむでいる | 定位原形词尾没有完成相应音便或し接续 |
| 読む→ている：よんだいる | 定位把过去接续用在て形连接处 |
| 買う过去：かた；書くて形：かて；起きる过去：おきった | 检查分类与局部错误的竞争，不抢先扣分类分；提供已知词类下的基本操作检查 |
| 已提供書いてある，否定答かいてあらない | 只评估ある的否定例外 |
| 已提供たがる／たい，否定过去只写到正确ない形 | 确认已完成的否定规则，只追加过去变化一步；不给未确认的复合／应用知识点扣分 |

命令形よ的依据是[東京都立大学公布的活用表](https://metro-noix.tmu.ac.jp/article/0008.html)。测试另外固定了正确词形，防止仅从同一个活用器生成正例时，把遗漏的合法变体也漏掉。

## 原始预期的复核

最初 348 个种子有 43 个与实现严格不符，不能全部称为缺陷。修复后，与冻结原始预期仍有 22 处分歧：4 个是上述词库外探针，18 个有逐项复核记录。

- 音便遗漏与完整其他形式／其他词类重合时，原预期直接扣音便也过强，应先确认；复杂多处改写同样保留拆步。
- 行く例外、副词形的い→く，最初使用了过宽或不同层级的知识点 ID；按已有共享规则修正测试映射。
- 漏ら与写成口语可能形、漏使役片段与写成受身等解释，若都指向同一接续规则，无需仅因语言解释不同就强制拆步。
- 4 个完整其他词类构形保留项目既有分类归因政策。它是评分约定，不是学习者心理原因的证明；出现另一个明确支持的局部操作候选时，新的冲突测试必须阻止直接扣分类分。

原始 `expect` 没有回写。复核文件为每项调整另存理由与检查约定，测试同时验证原始语料摘要，避免悄悄改变先验。汉字对照继承相应种子的复核。

## 可重复运行

```bash
npm run test:independent
```

此命令运行冻结语料、精确回归、变体保护和审计反向测试，已包含在常规 `npm test` 与 CI 中。反向测试会故意删除归因、伪造分类／复合扣分、删除过去探针，要求审计失败。

- `tests/fixtures/independent-inputs.json`：348 个原始种子及 96 个书写对照。
- `tests/fixtures/independent-input-provenance.json`：各组数量和原始摘要。
- `tests/fixtures/independent-input-reviews.json`：18 项预期复核和 4 项范围标记。
- `tests/independent-corpus.test.mjs`：440 个网站范围输入，以及 16 个初始错误 × 3 种后续策略的 48 条完整队列检查。

队列检查覆盖重复提交、同一知识点重复计分、诊断性分类零计分、范围越界、基本节点重复与有限结束；另外用实际页面验证新的过去单步补查、片假名误写归因、保存次数和 Enter 操作。
