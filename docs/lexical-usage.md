# 词义与练习搭配审核

当前审核版本为 `1`。`lexical-usage.mjs` 静态登记现有 156 个动词、91 个形容词的表记、读音、页面释义和活用类别。审核对象是这个词条展示的词义，不是同一汉字的所有读音或所有词典义项。新词、改读音或改释义都需要重新审核；运行时不能根据词表自动给新词放行。

## 构形与教学资格分开

- `supportsVerbForm` / `supportsAdjectiveForm` 只判断所教形式及词类构形边界。例如非五段、す结尾五段不能使用本课的使役受身缩约规则。它们不把“不宜作为日常题目”误称为“无法构形”。
- `assessFormUsage` 返回 `status`、`category`、`reason`、`reviewVersion`，以及可选的已审核 `context: {id, text}`。未知词义还标记 `reasonCode: 'unreviewed-lexeme'`。
- `allowed` 可直接出题；`context-required` 只有带审核语境才可出题；`blocked` 不出题。`morphology / semantic / context` 区分构形不适用、当前词义不匹配、参与者或语境不足。
- `eligibleVerbForm` 保留布尔入口，按上述教学资格返回结果。完整词形识别使用构形入口，并携带语义审核状态；不能因一个形式被移出常规题库，就把它误归成为词干或音便错误。

中文语境只给角色、对象和话题，不给日语答案、不预设该动作已发生，也不预设肯定、否定或过去。复合形式沿用对应表达族的审核和语境；整体多步组合另有人工审核，不能把每个中间形式当成原词的一次独立指令来过滤。

## 规则边界

| 规则族 | 审核方式与边界 |
| --- | --- |
| 分类、基本活用、常规条件连接 | 全部已审词义可练。保留「死ぬ」等罕见词尾的常规て形、过去形，避免语义过滤损害基础规则供应。 |
| 可能与态 | 分开审核能力、被影响者、安排者等角色。自动词受身可有日常语境，如雨对出行者、哭泣对照护者的影响；不按及物性一概禁止。 |
| 愿望、指令、尝试 | 不共用一个“意志动词”开关。「分かりたい」「忘れたい」「変わりたい」等可保留；天气义「降る」的たい／たがる不作为普通人的愿望动作。 |
| てほしい／てくれる | 自然事件可成为期待对象或受益来源，但需说明角色。没有自然对应日语的中文场景不能作为批准理由，例如当前「要る」义不采用「要ってほしい」。 |
| てある | 可见结果与为目的事先完成两种用法分别审核。保留「話してある」「読んである」的准备语境；「開く（あく）」不能借用「開ける」的人为结果义。兼容导出 `TRANSITIVE_VERBS` 实际是此表达的已审用法集合，不是完整词典及物性判定。 |
| 持续、结果、发展、程度 | 非意志事件仍可自然用于「増えていく」「壊れてしまう」等形式。「いる」「要る」的纯状态义不机械重复为ている。 |
| ようとする | 区分有意尝试与事件即将发生。花朵开放前的场景可支持「咲こうとする」，不能据此放行“花朵主动打算”的独立意向题。 |
| ながら／つつ | 本课只教同一主体的同时动作。不能用「知りながら」的逆接含义兜底；侧重到达或结束的孤立词条没有已审持续场景时也不出题。 |
| 多种表达组合 | 尝试＋愿望、受身＋状态、使役＋允许使用已有已审词单；受身＋愿望另审核愿望主体确实能自然承受该动作。不能把对象可被喝、可被吃直接解释成这个对象在表达愿望。 |
| 形容词 | 词类构形边界与具体用法分开。普通体谓语「普通だ」可练；当前普通义的常规连体形式为「普通の」，不以「普通な」为默认题。好き／嫌い／欲しい等く／に形给感情或状态变化场景，避免机械翻成“喜欢地／想要地”。 |

## 小候选池增补

新增 8 个常用动词，并为 13 组已有词与组合审核日常语境。新增词先开放分类、基础活用、受身及明确批准的组合，其他表达保留未审核状态；例如「嫌う」不会自动进入命令、意向或尝试题。原有词条的其他限制和语境保持不变。词例、适用范围及候选池变化见 [自然例词增补](natural-word-supply.md)。

## 验证约束

专门测试覆盖全部词义的审核身份、未知词义关闭、三种返回状态、复合与缩约继承、完整构形不受教学过滤影响，以及语境不得泄漏日语答案或固定时态／极性。独立审核补充反例。课程供应、知识点覆盖与历史复测迁移由统一目录审计和学习模拟检查；不能靠降低课程达标阈值或重新放行不自然搭配解决卡点。

## 参考依据与解释范围

- [东京外国语大学：Vてあります](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/046.html) 区分有意作用留下的结果与为目的事先完成，后者包括「話してあります」「調べてあります」。
- [国际交流基金：意志动词与无意志动词](https://www.kyozai.jpf.go.jp/kyozai/material/BTS00003/ja/render.do) 明确同一动词会因用法改变意志性；本项目据此分别审核表达族，不把所有后续接续建立在单个词级布尔值上。
- [国际交流基金：ながら](https://www.jpf.go.jp/j/project/japanese/teach/tsushin/grammar/201703.html) 区分同时与逆接用法，当前课程只取同时用法。
- [东京外国语大学：现代日语受身研究](https://tufs.repo.nii.ac.jp/record/939/files/dt-ko-0111010.pdf) 涵盖雨等自然现象的受身表达，支持保留有明确受影响者的自动词受身。

具体词条的 `allowed` 或场景选择是面向当前初学者词条练习的保守产品审核，不声称已穷尽所有方言、拟人、文学或其他语境中的日语表达。
