# 完整词形识别

判分先接受本题的所有合法变体，再针对当前词项查找课程注册的其他完整词形。识别使用共享题型列表、适用词条条件和活用器，不使用编辑距离或词尾猜测；形式标签与题干共用一份定义。词项索引有容量上限，避免长时间练习持续积累缓存。

支持当前 134 种题型、汉字与全假名，以及现有归一化规则下的片假名、半角和标点。相同字面形式可能对应多个目标，例如食べられる同时匹配可能形和受身形；本题可接受时仍优先判对，其他场景保留全部匹配标签，不猜测用户意图。

例如「座る → 普通体否定过去形」回答「すわりませんでした」，反馈明确识别为礼貌否定过去形，不再提示ア段词干错误。普通体否定、过去、否定过去的题干标签已明确语体。

识别出的完整其他形式不能作为原词词类、词干或音便错误的依据。已有精确的目标接续/组合评估、同表达形式切换补查和正确中间形式跳步继续保留；识别信息补充到反馈，原题仍按要求的目标判分。给定词干、分类选择及基本操作等微步骤继续按其限定范围评估。历史日志不回写，新反馈文本通过既有日志记录。

不属于当前词项的答案、拼写损坏和未收录表达继续走原有诊断。识别到某个完整形式，并不等于能从一次输入确定学习者真实的错误原因。

测试从课程列表独立枚举形式与变体，要求全部形式都有识别覆盖，并检查同形歧义、原题正确优先、特殊辅助动词、计分隔离和页面日志。原有错误模式生成器也会排除把完整其他形式直接归因到词干或音便的断言。
