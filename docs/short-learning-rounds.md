# 小候选池与短学习轮次

## 原问题

旧混合模拟的ます形课连续出现 97 道题。后半段只剩する／来る的连用词干未恢复，但同一道题一轮只能出现一次，于是每轮只练到这两个例词，剩余位置由已掌握的其他ます形题补满。最后 47 题中只有 7 题推进未达标规则，40 题是无助于该缺口的补题。

原有 `redundantFocusQuestions` 只计“分配给本轮主重点且该重点已经达标”的题，漏掉了换成其他已掌握知识点的替补。

## 调度修改

学习轮次仍以 12 题为上限。每个位置先检查是否还有本轮未用过、能够推进未达标规则的例题。已经全部用完时返回较短的题目列表；替补只可转向仍能推进学习的题目，不再重复相同整题或用已达标题凑满。

原有 3:1 的已学知识点穿插仅在仍有可推进例题时保留。明确进入课程巩固模式后仍可练满 12 题。

“可推进”按独立正确作答实际能提供的证据判断：

- 规则的独立表现尚未达标，或者题目包含尚未完成的覆盖项。
- 如果父知识点只差某个覆盖项，不含该覆盖项的普通题不算可推进。例如只差する／来る时，不再认为任意ます形题都能补齐父知识点。
- 动词变形答案不提供词类判断的独立证据，因此不能用未达标的分类标签把普通变形题算成必要练习。

页面在短列表结束时显示本轮结果，进度、得分分母按实际题数显示。下一轮继续未完成的知识点，不会因提前结束而加分、清除待复测或改动历史。提示和错误产生的独立复测，以及至少两道其他整题的间隔，仍使用原来的调度与评分；即使学习候选已经耗尽，合法的复测和间隔题仍能显示。

## 统计与审核

新增 `masteredOnlyQuestions`、`masteredOnlyByFocus` 和逐轮计数，统计作答前已经无法推进任何未达标知识点的题目，不受其是否为主重点限制。它包含正常穿插的已学内容，因此不应把总数全部称为无效题；但不能再用旧窄口径的 0 宣称没有补题。

知识模型审核改为检查统一路线实际使用的规划器。允许短轮次，但短轮结束后若仍有未用过的可推进题目则报错；依然检查课程归属、不重复整题及所需覆盖。旧引擎模型的固定长度审核不变。

## 对照结果

使用同一混合作答策略：每个被练到的重点首次定位错误、之后提示作答、查看答案、无归因错误，再独立答对。该压力测试不代表真实学习者必定要做的题数；真实页面的独立复测另有状态和 UI 回归。

| 指标 | 修正前 | 修正后 |
| --- | ---: | ---: |
| 全对统一路线题数 | 608 | 608 |
| 全对过去形连续题数 | 26 | 26 |
| 混合统一路线题数 | 1614 | 1512 |
| 混合ます形连续题数 | 97 | 45 |
| 完成的达标知识点 | 119 | 119 |
| 完成的覆盖项 | 89 | 89 |

单独恢复する／来る词干的回归从一次独立错误开始，仍需要 9 次独立正确作答，短轮长度为 2、2、2、2、1；其间不插入已达标题。没有降低 85% 的表现达标线、最低证据要求或覆盖门槛，也没有加入时间间隔。

测试包括小池、消耗过的题目、只差覆盖的父知识点、分类证据保护、短轮次后的恢复、完整复习轮次、统计盲点、真实混合路线，以及页面短轮显示和使用提示后的独立复测。
