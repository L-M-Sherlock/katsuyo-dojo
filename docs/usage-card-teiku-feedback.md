# 「ていかなかった」反馈核验

2026-09-21 核验用户反馈中的两个不同判断：空间移动、携带与做后离去可以使用过去否定；但“时间推移用法基本不成立”的概括过强，已有公开正文反例。

## 已核验的实际用例

以下均读取原网页正文及前后文，不以搜索摘要作为证据。

| 来源 | 原文短引 | 实际范围 |
| --- | --- | --- |
| [冈山市，2022-07-26 市长记者会](https://www.city.okayama.jp/shisei/0000038101.html) | 「若干増やしましたけど、それほど増えていかなかった」 | 出租车优惠券销售地点有所增加，但后续增长有限；不是空间移动，也不是完全没有增加。 |
| [厚生劳动省，第106回年金数理部会](https://www.mhlw.go.jp/stf/newpage_64163.html) | 「80年代くらいからフランス、アメリカはそんなに下がっていかなかったのに、日本はどんどん下がっていった。」 | 比较各国出生率的历时变化；「そんなに」否定下降程度，不表示完全没下降。 |
| [教育家庭新闻，2005-09-03 访谈](https://www.kknews.co.jp/maruti/interview/050903_1a.html) | 「予想したほど学校現場は変わっていかなかった。」 | 回顾多年教育改革未达到预期变化程度。 |
| [RADWIMPS 官方博客，2018-08-10](https://radwimps.jp/wimps_repo/post_10005/) | 「何度ツアーをやれど友達バンドは増えていかなかった。」 | 反复巡演中交好的乐队数量没有增加；属于实际叙述，不是语法教材。 |

这些材料足以反驳时间发展义的整族禁用，但不能据此宣称每个动词都自然、该形式非常常用，或直接批准「死んでいかなかった」等未见于这些材料的原句。多主体、时间跨度、程度词也不能机械构成批准条件。

## 审核口径

区分形式是否存在、具体句子是否自然、是否适合当前教学卡。否定可以落在一次事件、继续发展、发展程度或动作加离去上，须以完整日语及场景判断；普通否定和「〜ことはなかった」不能作为无条件替换规则。

用户对孤立的「動物が死んでいかなかった」提出自然度疑问有审核价值；但“日本人大脑无法捕捉未发生过程”的解释没有本次可核验依据，不纳入教学规则。
