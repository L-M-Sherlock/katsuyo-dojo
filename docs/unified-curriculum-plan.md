# 动词与形容词统一课程规划

状态：统一模型已实施。第 1、3 节记录当前六阶段口径与推荐课程顺序，后文保留原规划的技术约束及历史实施、验收记录。

## 1. 目标与默认方案

统一为一个自适应入口、一张知识依赖图和一份掌握度记录。动词、い形容词、な形容词继续作为题目类型存在，专项练习保留按类型筛选，但筛选不再创建独立学习路线。

课程按每门课引入的主要学习目标，显式分为“基础变化、可能与态、连接与条件、意愿与要求、动作与状态、综合运用”六组。分组回答学什么，顺序回答先具备什么、能复用什么，解锁检查实际先修和学习进度。分组与推荐顺序分别声明，同主题不强制连续；阶段不是严格的语法分类、难度等级或整组硬门锁。

保留 43 个现有课程 ID、119 种动词形式、12 种形容词形式及分类题。本次阶段调整只统一分组口径和推荐顺序，并显式调整共享词干的引入课程；不改变知识点 ID、既有作答统计、答案或判分方式，也不扩展名词、敬语等内容范围。

本项目的范围是给定词的构形练习，不是全面的句法或语用课程。编排根据词形变化所需的规则、复用和对照安排，不以句子语用复杂度作为延后构形训练的理由。

## 2. 统一模型实施前的问题（历史）

以下是原统一规划需要同时解决的问题，保留用于说明后续模型拆分与迁移约束。

- 37 门动词课程与 6 门形容词课程分别建模，页面将两份模型拼接后，再按当前领域过滤选题和解锁。
- 相同的变化规则分别记录。例如 `adj.suffix.i-past` 与 `composition.i-adjective.past` 都涉及「い → かった」，但后者还包含“对接续结果继续活用”的应用能力，不能直接当作完全相同的原子合并。
- 动词的否定过去形、部分否定接续也会复用形容词式变化，不能只处理「たい」。
- 知识点的首次课程、顺序和部分覆盖条件由遍历题库推导。直接重排课程会隐式改变这些信息，需要改为显式声明。
- `たい／ながら／すぎる` 等当前复用了完整 `masu` 所需原子，导致没有实际写出「ます」也可能给 `suffix.masu` 计分。统一时应拆出连用词干，按实际执行的步骤计分。
- 当前进度百分比主要围绕本轮重点／课程新引入原子计算。合并后必须区分“本轮重点达标”“本课达标”和“路线完成”。
- v5 只有累计统计，没有完整作答事件序列；旧 EMA 不能通过简单相加、平均或取最大值可靠合并。

## 3. 当前阶段与推荐课程顺序

阶段名称采用统一的教学目标口径：

| 阶段 | 课程数 | 归组依据 |
|---|---:|---|
| 基础变化 | 11 | 词类识别和基本肯否、时态、礼貌、修饰、连接形式 |
| 可能与态 | 4 | 表达可能、受身、使役与使役受身 |
| 连接与条件 | 9 | 连接动作或命题，表达条件、让步、同时发生与列举 |
| 意愿与要求 | 10 | 表达愿望、意向、尝试意图，以及请求、命令、禁止、许可与义务 |
| 动作与状态 | 7 | 描述动作的状态、授受、尝试、完成、准备、方向与程度 |
| 综合运用 | 2 | 复习态的后续变化，组合受身、たい和否定过去 |

排序优先级如下：

1. 实际先修先于依赖它的目标；只有模型中明确声明的先修关系构成硬约束。
2. 原生基础规则先于对派生结果的后续应用。例如先掌握基础过去变化，再练习对たい等表达继续变过去。
3. 共用规则在首次需要它的课程引入，不为保留旧引入课程而拖延当前构形训练。
4. 同等就绪时，按项目的词形训练目标、规则复用和形式对照安排。主题相邻是次级考虑，不强制同组课程连续。

`COURSE_ORDER` 独立显式声明推荐顺序，不再由分组配置逐组展开产生。分组配置负责课程归属与展示，顺序配置负责推荐优先级，先修图负责知识点开放。当前顺序把可能与态四课移到基础变化之后；后续各表达组之间的先后也是教学推荐，不代表彼此存在必需的先修关系。Yokubi 原课号仅作为内容来源保留，不表示本项目的学习顺序。

课程自动包含后续时态时，仍按最初引入的基础学习目标归组。例如たい及其后续变化属于意愿与要求，ている及其后续变化属于动作与状态；不能因为出现复合题就将整门课归为“复杂组合”。课程内部继续区分“接续入门”和“接续后的变化”：先学会 `たい`，再开放 `taiPast／taiNegative／taiNegativePast`，不能因为放在同一门课中就同时出题。

原来集中在 `multiStepCompound` 的 48 种普通接续后续形式已移动到各自基础表达课程。最后一课仅保留 `passiveDesireNegativePast`，训练受身＋たい＋否定过去。原 `voiceCompound` 的 12 种形式在相应的可能／受身／使役／使役受身课程引入，该课程保留为综合复习。复习课程可重复引用形式，不创建重复原子。

形容词副词形保留在第 6 课，作为基本修饰形式学习；ながら／つつ仍归连接与条件，使役、受身和使役受身仍归可能与态。本次将可能与态四课前移至第 12–15 课，共享词干 `stem.godan.e` 在首次需要它的 `potential` 课程显式引入，之后的 `ba` 和 `imperative` 复用同一记录，不再等待原引入课程ば形。课程与知识点 ID、全部 131 种活用形式、已有统计和作答判分保持不变。

“可能 → 受身 → 使役 → 使役受身”是构形训练的教学顺序，便于安排规则复用和形式对照。当前模型没有把 `suffix.causativePassive` 硬性依赖于 `suffix.passive` 或 `suffix.causative`；课程先后不能被解释为新增了这些依赖。各课的后续变化仍在本课内按实际先修逐步开放。

综合复习课若没有独有的新原子，使用明确的复习完成条件与课程覆盖记录，不凭空新增“综合能力”原子或要求空原子集合达标。

## 4. 共享规则与应用能力

### 可以共享的内容

- い形容词式的过去、否定、连接等变化：基础形容词与 `たい／てほしい` 的对应步骤共用同一个规则记录。
- 对「ない」继续变为过去／连接形式时，复用对应规则；「ないで」作为独立接续保留，不能与「なくて」合并。
- 接续结果确实是一段／五段／不规则动词时，复用相应词干、接续规则，并保留 `ある／いく／くる` 等适用例外。
- 连用词干与礼貌后缀分开：「読みたい」可验证「読む → 読み」与「たい」接续，不验证实际未执行的「ます」附加。

### 继续独立的内容

- 原词的动词／形容词分类，形容词「いい」系列例外，以及逐词例外。
- な形容词的「だった／ではない」与い形容词的「かった／くない」；意义相近不等于同一规则。
- 每种表达的接续，例如 `construction.tai` 与 `construction.tehoshii`。
- 把规则应用到接续结果的能力。例如 `apply.tai.continuation` 与 `apply.tehoshii.continuation` 建议分别记录，防止只练たい就自动判定会てほしい。

现有语义不变的原子优先保留 ID；共享原子不必为了命名整齐而全部改名。真正拆分、合并或改变测量含义的原子使用新 ID，并有显式迁移表。

应用原子原则上按基础表达分组，其过去／否定／否定过去作为覆盖项，避免为每个表达×每个词×每个词尾创建一个新原子。达标需满足现有证据阈值以及本组必要覆盖；不能把尚未开放的其他表达列为它的覆盖条件。最终数量在完整原子清单审计后固定，不预设合并一定会让总数减少。

### 以「申し込みたくなかった」为例

1. 由「申し込む」构造连用词干。
2. 接上「たい」。
3. 对接续结果构造否定，再变为过去。

完整答对可为实际执行的基础规则、接续和应用提供证据。同一份答案中，同一原子只更新一次。

若题目已经提供「申し込みたい」，只验证剩余变化及其应用，不再给动词分类、连用词干、たい接续加分。也不能把它算作“已能判断一个独立形容词的词类”。

错误归因沿用当前保守原则：只更新明确定位的原子；无法定位只记整题错误，安排拆步。即便只剩一个当前教学重点，也不把未知错误直接归给它。

## 5. 先修、解锁与题目步骤

用统一原子注册表显式声明：原子含义、先修、引入课程、适用输入类型、覆盖要求。课程排序只负责优先级，不负责隐式生成原子身份和依赖。

关键依赖示例：

- 形容词基础规则先于动词否定过去的对应应用。
- 动词连用词干 → たい接续；动词て形 → てほしい接续。
- たい接续＋所需的い形容词式规则 → たい后续变化。
- てほしい接续＋所需的い形容词式规则 → てほしい后续变化；不把会たい作为它的语法先修。
- ないで → ないでください；なくて → なくてもいい。
- 意向形 → ようとする。
- 可能形显式引入五段 e 段词干，ば形、命令形随后复用；共享词干的引入课程不是任意使用该词干课程的自动访问授权。

以上实际先修与第 3 节的教学顺序分别管理。可能、受身、使役、使役受身的推荐先后，以及连接与条件、意愿与要求、动作与状态之间的推荐先后，不自动转化为课程或原子依赖；解锁只检查模型明确声明的约束与学习进度。

新课程按先修就绪状态开放，推荐顺序按上表排序。取消“另一个无关的已开放知识点没达标，就禁止开放所有新知识点”的全局依赖；已学但回退的薄弱点仍优先安排加强。新手默认跟随推荐顺序，专项练习可选择已开放课程。

旧用户的历史课程访问权限与本次推荐焦点分开处理：已开放内容可继续诊断式练习；新推荐先补当前目标缺失的共享规则，不要求把原有动词成绩清空后重走路线。历史访问权限不等于先修达标：缺少新先修时，可以保留练习证据，但不能据此宣告应用达标或继续解锁其后续内容。

题目要有真实的步骤序列，至少记录输入／输出、执行原子、已提供的前置条件和可诊断的错误模式。统一模型实施前，`operations` 大量重复整题输入输出，不能直接当作精确步骤使用；统一计分、拆步和解释因此需要消费同一份真实步骤描述。

题目可跨原词类型抽样，原词类型只用于题目生成、说明和专项过滤。掌握度按实际步骤更新，不能根据题目来自“动词区”或“形容词区”决定记录位置。

## 6. 旧进度迁移

采用 v6 数据结构、独立存储键与新版导出封装；继续支持导入 v5。已有 v4 导入规则保留兼容，但不能假定其混合统计能恢复为原子历史。

本次重排不升级存储格式或 schema，仍为 v6；课程编排版本为 `CURRICULUM_VERSION = 3`，记录在 `profile.curriculumVersion`。五段 e 段词干的引入课程曾由命令形移至ば形，本次再移至可能形，因此按旧编排版本保留已经获得的专项访问：

| 课程编排记录 | e 段词干引入归属与访问兼容 |
|---|---|
| 版本 1，或无版本标记的旧 v6 | 已引入 e 段词干时，保留命令形专项访问 |
| 版本 2 | 已引入 e 段词干时，保留ば形专项访问 |
| 版本 3 | 在可能形课引入 e 段词干，不据此提前开放后面的ば形或命令形 |
| 任意版本已有显式课程访问记录 | 原样保留，不因引入课程重排而撤销 |

这是历史访问权限的兼容处理，不改变先修规则，也不重置、复制知识点分数或改动原子 ID。

| 旧数据情况 | 迁移策略 |
|---|---|
| 含义不变或严格一对一重命名 | 保留完整统计及必要覆盖；按目标规则重新验证达标条件 |
| 已有基础形容词规则记录 | 作为相同共享规则的基线，保持原有统计口径 |
| 旧复合原子同时包含规则和应用 | 保留为历史证据，不能复制成两份独立的已掌握记录 |
| 一个旧原子拆成多个表达应用 | 不把总记录分发给每个新原子；按实际缺口安排确认练习 |
| 多个旧原子映射到同一新原子 | 使用明确指定的语义等价基线；其余保留归档，不相加、不平均 EMA、不取最高掌握度 |
| 没有可用的等价基线 | 显示“待确认”，通过独立作答建立新证据 |
| 旧课程顺序／动词与形容词偏好／核心范围 | 映射为历史课程访问权限和专项筛选偏好；不再生成两条自适应路线 |

每日题数、正确数和连对按日期兼容保留。原子数量变化时说明新旧计数口径不同，不能让用户误以为原有成绩被删除。

先生成迁移报告：保留多少项、哪些需要确认、推荐从哪里继续。迁移必须幂等；原始备份不写入仓库。新旧存储键隔离，保留 v5 原始快照；旧标签页继续写入 v5 时提示存在旧版记录变更，不自动覆盖或猜测合并进 v6。沿用 Web Locks、快照冲突检查与写失败保留内存记录的机制。

针对“动词学到后期，形容词只有分类记录”的老用户：保留未改变语义的动词规则与历史访问权限，优先补测基础形容词变化。旧复合成绩可用于安排有针对性的确认题，但不能直接推定基础形容词分类、例外、所有应用场景均已掌握。

## 7. 界面与交互

- 一个“自适应训练”入口；用六个学习目标阶段和课程目录展示统一路线，课程列表使用新的路线序号，原 Yokubi 课号只表示内容来源。
- 知识进度抽屉提供“课程如何安排”折叠说明，分别说明归组、排序与解锁：归组读取与阶段目录相同的目标配置；排序说明先修、规则引入、复用与对照；解锁说明实际先修和学习进度，不设置整组门锁。

- 接续课程直接显示「たい的过去／否定／否定过去」，在解析中说明使用的共享规则，减少抽象标签造成的跨路线误解。
- “当前重点掌握度”“本课必学内容达标数”“全路线已掌握原子数”分别展示；当前重点 100% 不再让整个课程卡片看起来已完成。
- 课程独有的新知识与复用规则分别列出；全局统计去重，但课程达标需满足本课要求和本课应用覆盖。
- 学习来源链接按具体题目保留。混合课程可以引用多个原始课号，不制造新的 Yokubi 课号。
- 保留整题判分、笔误重试、保守归因、拆步计分和 Enter 推进。拆步不增加整题数量或连对，已提供步骤不计分。

## 9. 验收标准

- 原有 119＋12 种形式及分类题全部可达；移到新课程的形式保留正确答案、接受变体、适用词限制和来源。
- 依赖图无环、无不存在的先修；每个新原子有足够的引入题目，至少能取得现有达标阈值要求的证据；每轮不重复题目。
- 高かった与読みたかった的对应过去变化更新同一共享规则；单独做对高かった不自动把たい应用标为掌握。
- 会たい不自动等于会てほしい；会共享过去变化不自动证明能处理いい例外、な形容词过去或原词分类。
- 已提供中间形式时不重复计算前置步骤；同题同原子不重复写入；未知错误不兜底扣分。
- 所有进度迁移不伪造事件顺序、不放大证据、可重复执行、可恢复原始备份；旧标签页与写入失败测试通过。
- 基础练习只做动词或只做形容词都能贡献对应共享规则；专项筛选本身不授予课程访问权限或绕过应用先修，历史课程访问兼容按迁移规则单独处理。
- 课程 100% 与本轮重点 100% 含义明确；没有独有新原子的复习课仍能合理完成。
- 正确学习和混合错误模拟覆盖统一路线并可完成；额外覆盖未知错误、拆步成功／失败、历史弱项回退和老用户补测路径。
- 全部单元、交互、知识审计、学习模拟、类型检查、Lint、构建通过；浏览器验证键盘、输入法和移动端布局。

## 10. 规划阶段结论

原规划采用统一路线，把形容词基础放到动词复合活用之前，并把常见表达的后续变化从最后一课移到表达本身后面。当前六阶段在保留这些依赖约束的基础上，按每门课的主要学习目标统一分组，完整顺序见第 3 节。

共享原子的边界和旧进度迁移继续遵守原规划约束。分组描述主要学习目标，独立的推荐顺序先满足实际先修和原生基础规则，再安排首次引入、复用与形式对照；主题相邻是次级考虑，同组不强制连续。历史访问权限按编排版本兼容，并坚持不凭汇总记录复制掌握度。


## 11. 实施记录

- 新增统一课程、知识点、迁移与课程进度模块；保留旧模型供旧数据解析和兼容回归使用，界面运行统一模型。现有 43 门课程、131 种形式及分类题均保留。
- 「ます」旧统计曾被「たい／ながら」等题目混入，不能原样视为严格等价的礼貌接续证据，因此与旧复合统计一起归档；连用词干和真正的ます接续重新分开确认。不规则连用词干采用する／来る覆盖，近期错误仍降低掌握度。
- 统一模型显式区分「ある → ない」例外，避免将它归为五段ア段词干变化。「いい」例外在常规基础变化之后确认。
- 历史已开放课程可继续练习并积累实际证据；应用达标仍受共享先修和末尾覆盖约束。正常专项课程只提供先修就绪的题目。
- 巩固轮换包含没有独有新原子的态复合复习课，课程另存最多 12 道不同题目的正确作答证据；导入旧统计不会直接把复习课标为完成。
- 计分原子来自实际操作序列，解析展示同一序列的中间结果；拆步按照该序列划分前置与后续原子。未知错误继续保持不兜底扣分。
- 旧导出备份仅做只读迁移演练，不写入仓库。原始记录保留在新 profile 的 legacy 快照中，并随新版导出保存。
