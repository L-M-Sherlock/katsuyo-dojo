# 动作与状态用法卡审核

本轮范围为动作与状态的 7 门课程、53 种形式。原有 159 张代表卡，固定缺口清单有 6,845 个词义／形式配对，分为 199 个批次。现有 6,778 张通过并接入，67 个配对仍未决；动作阶段覆盖 6,937／7,004 配对。尚未完成全阶段覆盖，也未调整未决配对的出题许可。

内容位于 `app/lib/usage-cards/actions-generated.mjs`，全站目录共 16,376 张。动作扩充之前的 9,598 张卡保持原有 ID、顺序和对象内容；基线 SHA-256 为 `5f7f9dcef365905069a2d258a7581b5e3974044caf13bda7b74d959e40fdcfcf`。

## 课程扩展与语言复核

本项目可以扩展参考教材未详讲的自然用法。Yokubi 和既有中文概括是参考，不是排他边界；新增用法须同步更新课程说明，保持固定词义、目标词形、否定范围及语体。此次补充了てしまう否定的预防结果与过去否定疑问，以及てみる的经历后判断。

此前公布的 152 个未决配对全部重审：92 个通过，60 个保留未决。复查历史动作卡另撤销 7 个批准配对（要る的 3 个てしまう肯定／缩约／过去形，指す的 4 个てある族形式），合计 67 个未决。原有动作扩充卡另有 59 张修改了场景、译文或句子，包含字段标点修正，不作为模型错误率统计。完整疑点见[未决清单](usage-card-actions-pending.md)。

本轮历史交付由作者子代理编写、审核子代理分批复审，主代理核对争议和返修内容。期间发现模板审核理由、错误译文，以及返修未停写时被提前冻结的问题；相应旧批准已撤销，重新逐句复核并保留版本记录。曾推送的中间提交未发布，其 CI 已取消。结构检查和匹配哈希只能确认内容与记录一致，不能替代语言判断。

用户最新指定的后续流程为：作者子代理使用 `gpt-6-astra low`，主代理亲自逐卡审核、返修和批准，不再增加审核子代理。此前实际参与的审核身份保留为历史，不改写成主代理独审。

## 验收与溯源

[审核清单](usage-card-actions-review.json)保存原缺口校验和、旧卡基线、批准集合、最终对象校验和、批次信息与未决集合。当前有效配对须恰好等于已覆盖配对与明确未决配对的并集，两者不相交；同形式其他词不能填补缺少的词义配对。

199 个批次已通过当前全量预检。每次交付保存独立快照和 receipt；候选从通过校验的快照字节构建，拒绝冻结后漂移、旧审核句及未知状态。返修批次重新执行精确清单与读音检查，并人工判读词典候选。源稿保留 draft，只有批准集合转为网站的 approved。

发布前运行用法卡审计、全部测试、类型检查、lint 和生产构建；远端 CI 另执行知识审计、全对及混合路线模拟，并在全部门禁通过后部署同次构建产物。实际发布结果以 GitHub Actions 与 Pages 部署状态为准。测试不证明自然度，未决配对也不会因工程验证通过而自动批准。
