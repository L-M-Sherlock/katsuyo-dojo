| 变形 | 日语原句 |
| --- | --- |
| 渡す→渡さず | 書類を上司に渡さず、もう一度内容を確認した。 |

| 勝つ→勝ってもらわなかった | あの練習試合では、助っ人には勝ってもらわなかった。自分で戦った。 |
