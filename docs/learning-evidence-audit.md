## 必须满足的行为

| 不变量 | 验收要求 |
|---|---|
| I01 | 有效整题失败记录具体目标的独立失败与待复测；具体原子错因仍可未知。 |
| I02 | 自动拆步、给定中间式／词类、显示规则／答案、手动提示分别记录来源；辅助正确不变成独立正证。 |
| I03 | 辅助正确不增加原词分类、分类启发式、整体应用、形式覆盖的独立成绩。派生词的词类选择不能计到原词类别。 |
| I04 | 拆步完成不清除待复测，也不能单独触发当前达标。历史访问权限与历史覆盖可保留。 |
| I05 | 给定前提后的局部操作有辅助练习价值；已透露目标规则或答案后的成功属于练习记录，不是未提示能力的证明。 |
| I06 | 同一道原题里，同一知识点、同一诊断节点不会因共用或重复提交重复计分。拆步不增加原题题数、正确数或连对。 |
| I07 | 只为有明确证据的原子保存负证；不把原题焦点、揭晓或模糊错答当作确定错因。 |
| I08 | 笔误重试、无效输入不制造终局失败、正证或题数，也不清除待复测。未透露答案的词面纠正可完成一次独立题。 |
| I09 | 有效复测要求同目标形式、无帮助、不同词、满足间隔；同词立即重试、其他后续形式与辅助成功均不能冒充复测。 |
| I10 | 事件与终局问题有幂等标识；待复测按目标去重，历史失败不会被重放覆盖。 |
| I11 | 到期复测进入有限调度，不被其他薄弱点永久挤出，不让一个词无限霸占。没有可换词时不得伪造通过。 |
| I12 | 刷新、导入、跨日、改变时钟不会制造作答间隔或清除待复测。 |
| I13 | 旧 `step` 即使 `hintUsed:false` 也不是独立整题；只从完整、可验证的历史重建状态。 |
| I14 | 缺失日志不得补造独立成功或失败；旧证据的来源和局限必须保留。已知辅助加分不能继续无说明地证明当前掌握。 |
| I15 | 日志、证据通道、待复测和每日统计一次保存；冲突全不提交，写入失败后能导出同一内存快照。 |

这里的“独立成绩”指用于表示无帮助掌握、形式覆盖和当前达标的证据。实现可以另设辅助表现通道，也可以保存条件化观察，但不能仅用降低一点权重的方式让重复辅助答对最终变成独立达标。

## 重点反例

- `のっていた` 用于要求否定的题：即使具体原子不明，目标形式的独立失败是确定的。
- `ふせたがれない`：词面与变化都有差异，不应猜某个原子错，但也不能把整题失败丢掉。
- `おくれたがた`：派生词五段／一段混淆与漏促音均可解释。给定派生词与正确类别后写对过去形，只支持该条件下的表现。
- `待つ → ておる・过去形`：前后两段都涉及促音便，不能在同一道辅助流程里重复增加同一原子的成绩。
- 原题失败后立刻重答同词正确：可能是短期记住刚显示的答案，不能清除换词复测。
- 否定题失败，隔几题写对同家族过去题：目标不同，不能清除原来的否定待复测。
- 查看规则后收起提示再提交：帮助历史仍然成立。
- 导入第 17—20 条旧日志：拆步正确不能覆盖较早的原题独立失败，重复导入也不能重复记分。

## 显式预期复核

新策略明确复测目标包含“目标形式与具体操作路径”。因此从「乗る」换成「書く」虽然形式相同，但促音便与イ音便路径不同，不清除原题待复测。两个原始种子的 `pending:false` 预期保留在冻结文件中，单独在 `independent-learning-evidence-reviews.json` 记录改为 `pending:true` 的裁定与理由，并补充「乗る → 取る／待つ」的同路径正例。

纯词面笔误重输且未透露目标规则或答案，保留独立语法资格。`hadFeedback` 接口表示语法／答案反馈，不表示纯词面提醒；两个笔误种子的原始预期没有修改。

## 生成审计中的计分检查

`scripts/lib/learning-evidence-contracts.mjs` 把渠道不变量接进两套实际生成审计。`audit:diagnosis` 的 `evaluateGeneratedCase` 和 `audit:paths` 的 `auditUniversalCase` 都逐输入调用页面使用的 `applyLearningObservation`，同时保留原有 `updateKnowledgeStats` 算术、归因、路由与队列约定。

每个输入执行六种条件：实际上下文、给定中间式、手动提示、语法反馈后的重交、揭晓答案、过早的同词练习。每个可提交条件再重放相同问题／事件 ID，检查幂等。笔误和无效输入仍检查零写入，另把揭晓作为明确的独立动作检查。辅助主分、非局部辅助记录、漏记局部证据、错误的速度证据、重复原题计数和丢失待复测都会使审计失败。

连续路径审计还累积真实 profile：每个实际拆步都检查主 `byKc` 与 `independentByKc` 不变，`assistedByKc` 只写本步尚未评估的局部操作，原题待复测保留。旧队列算术检查没有被这些新断言替换。

`tests/independent-generated-learning-audit.test.mjs` 故意注入辅助加主分、辅助写分类／应用／覆盖、揭晓扣分、过早练习加分、误清待复测、重复提交和输入原地修改。两套入口都能拦住；也检查“所有渠道全不写”的伪修复不能通过。

审计报告新增 `learningAudit.version: 1` 及实际输入数／计分调用数；路径报告另有连续流程数／调用数。合并器拒绝没有渠道检查信息、调用数不足或与输入／流程数不一致的旧分片，避免把旧版绿色报告拼成新规则验证结果。
