# 词条与活用适用性审核

课程要求、覆盖关系和复测规则路径的冻结基线来自 `e34975d`，当时有 148 个动词、91 个形容词、18,221 道声明题。第一阶段增加词义与语境限制，得到 16,583 道可出题练习；第二阶段为小候选池补充 8 个常用动词，以及逐组审核的旧词多步组合。下面分别保留这三个阶段的数据。

教学筛选发生在完整课程要求建立之后。删去不适合的题目不会让知识点或覆盖要求跟着消失；增加例词也不会增加达标知识点、重置原分数或更换复测规则身份。

新增八词为「誘う、雇う、扱う、疑う、嫌う、からかう、祝う、追う」。非基础表达只开放本轮实际审核的受身及其后续变化、受身愿望组合，以及明确指定的受身进行组合；其余表达继续等待审核，不因新增词条而默认开放。

所有课程、目标形式、达标知识点和覆盖项仍有可用题目。词条身份包含读音及当前词义；复测换词沿用原有的读音与词类身份，变更语境不构成换词。

供给审核检查知识点所属课程中存在满足先修的练习，以及每个应用下的全部覆盖项。这里的先修供给检查设定其他知识点已达标；实际从零学习的顺序另外由全对、混合作答模拟与复测状态重放验证。

## 重现与持续检查

```sh
npm run audit:eligibility
npm run audit:eligibility -- --output /tmp/katsuyo-eligibility-audit.json
node --test tests/eligibility-catalog.test.mjs tests/natural-word-supply.test.mjs
```

JSON 报告比较的是**当前声明目录与当前适用目录**，包括每门课、每个目标形式、课程×形式、每个知识点、每个覆盖项和每条复测路径的前后题数及词数；还记录全部被排除题目的具体原因、复测路径的前后词例和所有失败项。

最初的固定基线位于 `tests/fixtures/eligibility-baseline.json`，未改写。`tests/fixtures/natural-word-supply-before.json` 另行保留本轮扩词前的词条身份、适用题目和语境哈希、845 条规则签名及小候选池词表。新回归仅豁免逐项列出的已审核组合，拒绝借扩词放开其他旧限制。

测试与审计共同拒绝删去原要求、改动旧复测规则身份、未审核词义进入目录、缺少审核语境的题目、语境包含日文答案、某课程或目标形式无题可练等情况。

普通 CI 的 `Eligibility catalog` 作业独立并行，并上传 JSON 报告；发布门禁同时要求测试、构建与目录审核通过。大型错误生成审计仍由手动流程运行。

## 验证记录及范围

首轮适用性限制实施时，全套 734 项测试通过；当时的统一路线全对模拟以 608 道原题完成 119 个达标知识点及 89 个覆盖项，指定混合作答模拟以 1614 道原题完成同一范围。这些数字对应扩词前的 16,583 题目录，不能当成本轮扩词后的复跑结果。

本轮扩词专项 5 项回归与目录审核已通过，目录审核失败项 0。专项验证八词身份、其余旧题和语境完整保留、四个小候选池、既有规则与知识点不变，并确认增加候选词不会改分或清除原待复测，仍须两道其他整题后独立作答。

真实评估状态回放另覆盖错误原题、提示、拆步、两道其他整题、同规则换词复测，以及 0／1／2／3+ 个候选词、多个待复测和专项筛选。它与全对／混合知识图模拟互补；没有穷举任意用户历史和全部错误输入。

大型代表性与全量诊断／路径审计不属于普通轻量 CI，不能由这里的通过结果推断它们也已重跑。以上为发布前的本地验证结果。

### 扩词后的验证

新增例词后的完整 743 项测试全部通过，知识模型审核、目录审核、TypeScript、ESLint 和生产构建通过。全对统一路线完成全部 119 个达标知识点及 89 个覆盖项，仍需 608 题；混合作答模拟也完成全部范围，需 1614 题。四个重点小候选池及原记录兼容性有专项回归，详见 [自然例词增补](natural-word-supply.md)。这些结果不代表穷举所有错误输入或所有历史存档。
