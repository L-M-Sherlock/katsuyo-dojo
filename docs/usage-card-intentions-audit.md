以下五个配对未通过本轮课程用义审核，未批准为用法卡。它们的构形支持与题池保持原样，无匹配卡时界面按原规则不展示例句。这里的缺口被显式保留，不声称全阶段已完全覆盖，也不以搜索不足证明日语里不存在这种字符串。

| 配对 | 未批准原因 |
| --- | --- |
| 間に合う × ないでください | 原例句把“赶上时限”误作“到达地点”；具体礼貌要求故意错过时限的自然教材用例未获核准。 |
| 間に合う × 禁止形 | 原例句的桥头方向没有对应时限，不能表达赶上；目前没有核准自然的对人禁止语境。 |
| 間に合う × てもいい | 当前例句用赶上时限的结果询问“是否来得及”，不是清楚的行动许可；不能拿「間に合えばいい」代替完整目标。 |
| 間に合う × ませんか | 当前否定疑问通常是确认能否赶上，尚未核准自然的共同邀请用例。 |
| 分かる × ませんか | 当前句确认对方理解或认同，不是本课共同邀请；不能换成「分かり合いませんか」或「分かろうとしませんか」。 |

核对依据：[东京外国语大学「Vてもいいです」](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/058.html)、[「Vませんか」](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/062.html)。这些资料用于区分课程采用的用义，不代替原创例句的逐句审核。

## 语言审核与返修

制作先保存原始缺口清单、原有卡片对象与内容哈希，再按词义／形式分成互不重叠的批次。作者只写自己的草稿，审核者核对活用器实际生成的全文、假名、短场景和中文译文。稿件保持draft，只有当前对象与语言审核记录的哈希匹配并通过后才进入发布集合。

本轮发现部分初稿虽然结构通过，仍把词义直接拼入译文、给四种肯否时态复用冲突场景，或者用通用“准备执行”代替具体处境。早期的部分通过报告同样漏审了这些错误，因此撤销受影响批次的批准并重新实读、返修；不能把这些早期报告作为终稿质量证据。

明确修订包括：

- 区分愿望、尝试、已发生事实和能力不足；过去愿望不证明愿望实现。
- たがる保留第三人可观察背景；否定场景不能写“拿着已经脱下的鞋，却不愿脱鞋”等状态冲突。
- ようとする区分行动尝试与无意志变化的临界状态，避免把屋顶和零件写成主动尝试。
- 请求、命令、许可、邀请、义务各用本课指定用义；なくてもいい和义务构式的否定范围不反转原动作。
- 核对自他动词、对象和移动参照点：動く不是動かす，着る的衣物对象不能是鞋，飛ぶ的限定配对使用人参与飞行活动的语境。
- 中文译文只翻日文实际表达的信息，不把场景里的动作、原因或结果加进译文；改句后同步假名与ruby分界。

少数有真实依据但语用受限的卡片保留明确场景和答后说明。例如「分からないでください」采用心事被看穿后的羞恼抗议；「そんなに簡単に分かるな」采用老师告诫学生别草率领会的修辞语境。词义参考[小学馆《大辞泉》分かる](https://kotobank.jp/word/%E5%88%86%E3%82%8B-664717)，实际用法核对[アニメ私塾「簡単にわかるな」](https://animesijyuku.blogspot.com/2018/03/blog-post_89.html)及[小说中的情绪对白](https://www.alphapolis.co.jp/novel/528783686/859068333/episode/11478892)。这不表示这些是通用行政指令。

## 审核记录与验证

[发布审核清单](usage-card-intentions-review.json)保存本次批准的126个批次、内容哈希、审核责任和五个暂缓配对。测试逐批核对发布数组与审核哈希，并核对全部原有6,001张卡片未变；覆盖从实际课程与适用性规则推导，允许的例外只有清单中明确记录的五个未批准配对。

使用仓库的 `card-workbench check --assignment`、`reading-audit.py` 和 `npm run audit:usage` 校验内容；UniDic差异逐项区分合法异读、分词错误和真实读音错误，不自动覆盖。新增卡片仍使用原有真实组件，答前只挂载场景与挖空，答后显示完整句、注音和译文。

skill新增[意愿与要求专项规则](../.agents/skills/write-katsuyo-usage-cards/references/intentions-review.md)，协调流程补充当前卡片哈希、旧报告失效和同源错误复查要求。个人学习数据未参与内容制作或测试。

四组完整回归共895项通过（unit 552、ui 132、diagnosis 132、paths 79）；知识模型、适用性审计、全对与混合路线均通过，统一路线仍为684道全对模拟、1,688道混合作答。类型检查、lint、生产构建和skill校验通过。历史题池与评分逻辑未修改。

Windows本地的CI门禁脚本使用Git Bash验证。历史适用性哈希测试固定使用与原基线一致的英文排序规则，避免中文系统区域导致同一题池出现不同哈希；基线哈希和验收要求保持不变。

浏览器真实页面验证了自由挑战中たい否定过去卡的答前挖空、正确作答后的完整句和译文；自动交互回归继续验证拆步期间不泄露例句答案。完整新增卡片由UniDic-lite 1.0.8／fugashi 1.5.2作最终对照，词典候选仍逐项人工判读，不作为自动错误数。

更新后的skill另由未参与本轮编写的代理只读审核4张独立试作输入，正确区分3张结构合法但语言不合格的旧稿和1张应保留的自然否定许可句；识别了词义拼接、靴を着る及把分かる误当思う，并保留称谓母＝かあ，不用词典首选覆盖。试作未加入题库。
