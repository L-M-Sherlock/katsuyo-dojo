# 学习评估数据迁移

`restoreLearningAssessment(sourceProfile, { components, exercises, at })` 返回新的 `byKc` 和 `assessment`。`exercises` 必须是完整题库；只传日志中的词，不能据此判断某个变化路径是否只有一个可用词。

## 已有新版评估状态

`assessment.version === 1` 的状态是权威记录。导入时验证知识点、统计数值、目标标识、待复测状态与事件去重记录，随后恢复。保留的作答日志不会再次重放，也不会把已经独立复测完成的目标重新设为待复测。早期 v1 如果没有最近所用词的字段，只将 `lastPresentedWordKey` 缺省为原待测词 `lastWordKey`，不修改任何成绩或重新推算历史。

原题累计数与已记录的独立提交 ID 对账。每个目标的原题数之和，连同迁移时明确记录的元数据缺失题目，必须等于累计原题数。拆步记录不会增加这个计数。

## 旧版日志可以证明什么

旧的 `byKc` 混合了独立整题、提示和拆步的证据，不能凭累计数直接拆开。因此迁移只纠正日志能够核对的部分：

1. 对每个日志涉及的知识点，从当前 `byKc` 倒序核对 `change.after` 和 `change.before`。
2. 若所有快照连续、原词能在完整题库定位、旧更新与其原始判定一致，取最早一个 `before` 作为历史基线。
3. 按日志顺序，使用当时的正确/错误判定、明确归因与实际更新范围，重新应用现行证据规则。
4. 独立整题中仍可评估的原子进入 `byKc` 和 `independentByKc`。符合记录条件的旧独立速度增量一并保留。
5. 拆步、提示和已给出语法反馈的重试只记录局部规则的辅助表现；应用、覆盖和来源分类不会因此上升。查看答案不产生掌握证据。纯词面笔误或无效输入的重输仍可保持独立语法资格。

迁移不调用新版答案分析器重新判断旧输入，因此不会用新规则倒推当时未确认的错误。日志中没有实际更新的知识点，也不会凭当前题目定义补造正确记录。

没有日志、快照断链或原词元数据缺失时，相关累计统计保留为未核对的历史。不会清空全部进度，也不会把无法核对的记录假装成独立成绩。形容词 `iiFamily` 等信息取自完整题库，不从简化日志猜测。

## 待复测状态

可定位的旧原题失败会恢复待复测状态，即使当时无法确定哪个原子错误。提示和查看答案后的完成也保留独立复测要求。拆步答对、完成或跳过都不能解除它。显示提示即记录暴露，尚未提交原题时也可存在待复测目标：原题数和失败数仍为 0，失败时间为空。答对辅助原题也不会被伪装成答错，只保留独立复测要求。

只有真实原题提交推进题数间隔，跨日保留。无帮助但过早或同词的作答仍保留输入日志，其成绩和目标计数归入辅助练习，不能提高应用或覆盖。目标路径不同的题目不能相互替代复测。可替换词必须同时避开原待测词和最近一次同目标作答使用的词。

仅当完整题库证明目标路径只有一个可用词时，才允许同词复测；从最近一次同目标作答或辅助操作起，完成两道其他整题即可。当前策略为 `single-word-spaced`，没有任何时间延迟。旧 `single-word-delayed` 日志保留为历史记录并允许导入，但当前资格重新按题数计算。

## 对账报告

迁移报告保存在 `assessment.migration`，原始日志不改写：

- `at`、`throughSequence`、`originalLog`：迁移时间与已核对日志范围。
- `baselineByKc`、`verifiedKcIds`、`unverifiedKcIds`：可追溯旧基线及不能核对的历史范围。
- `changes`：实际改变的知识点与迁移前后快照。
- `knownIndependentEvents`、`knownAssistedEvents`、`unknownEvents`：按新规则分类的可见作答事件数。
- `unverifiedQuestionIds`：元数据缺失但能确认真实提交的原题；仍参与题数间隔。
- `events`：每条已处理作答对应的原日志 ID、序号、帮助条件及实际评估范围。
- `uncertain`：断链、缺失元数据、历史裁剪等无法还原的部分。

报告快照与当前统计分别保存，后续练习不会改写当时的迁移结果。

## 验证示例

2026-09-09 的本地导出包含 20 条日志、跨日 12 个真实原题。迁移中有 10 个合资格独立事件、8 个辅助或过早复习事件；完成拆步的 2 条日志不算作答。15 个知识点统计发生纠正，没有发现日志快照断链。

其中「乗る → ている・否定形」原答 `のっていた` 错误，后续 `のっている` 和 `のっていない` 是辅助作答：

- 「ている后续变化应用」由累计 3/3 恢复为两次独立作答的 2/2，原独立速度统计保持不变。
- 仅由拆步获得的「ている・否定覆盖」记录移除。
- 局部规则的两次拆步表现保存在 `assistedByKc`；来源分类不据此加分。
- 「乗る → ている・否定形」保留待复测状态。

重复导入迁移后的数据不会再次扣除这些记录。专项回归可运行 `node --test tests/assessment-transfer.test.mjs`。
