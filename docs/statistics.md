# 学习统计

顶部「统计」打开 `#/stats`。这是独立的页面视图；返回练习保留原题、已输入答案、提示、解析和拆步进度。统计页不响应练习的数字键与 Enter 快捷键。可使用浏览器前进、后退或直接打开链接。

## 统计口径

- **原题**：每道题第一次有效提交只计一次。答对、答错和揭晓答案都计入；无效输入、允许重交的笔误及拆步不增加原题数。
- **独立正确率**：合格的无辅助整题答对数 ÷ 独立整题数。提示、揭晓、辅助作答和未满足复测条件的练习单独记录，未知旧记录不进入分母。
- **复测成功率**：合格独立复测答对数 ÷ 合格独立复测次数。辅助复测、任务暂停、迁移或其他任务移除不计成功。
- **课程、知识点、待复测**：显示当前状态；动词和形容词共用的规则在全部范围中去重。课程表的原题数和正确率为累计值。
- **薄弱项**：仅列出已练习且尚未达标的已解锁知识点。尚未作答的内容不判为薄弱项。
- **错因**：只统计日志能够明确归因的原题错误；不能明确归因和答成其他完整形式分别显示。不会把一道错误分摊给全部关联知识点。

## 用时

计时仅用于描述练习，不影响掌握度、先修条件、调度或复测资格，也不会引入基于时间的间隔重复。

有效练习时间包括阅读题干、作答、拆步和阅读解析。仅在练习页面可见且窗口有焦点时累计；切到统计页、打开知识进度、后台、失焦和结束本轮会暂停。连续 60 秒没有键盘、指针或滚动交互后暂停，下一次交互恢复。

答题耗时从显示原题开始，在第一次有效提交时停止；允许重交的输入不重置起点。平均答题耗时只使用新版记录的独立正确原题。解析和拆步时间不会算入答题耗时。

用时在提交、切换页面、失焦等边界以及每 30 秒尝试保存，与学习记录使用同一写入锁。提交会等待正在进行的用时保存；计时写入不会覆盖刚提交的答案。浏览器突然终止时，尚未完成持久化的最后一段用时可能丢失。

## 历史、容量与迁移

Profile 为 **v8**，存储键为 `katsuyo-practice-profile-v8`，JSON 导出格式为 **6**；独立评估仍为版本 2。自动读取 v7/v6/v5 本地进度，并支持旧版 JSON 导入。旧标签页写入旧键不会覆盖新版。

- 累计统计长期保存；保留最近 365 天的日汇总，更早的日期合并为月汇总。
- 作答顺序按 50 道原题聚合，最多保留 1,000 个区间，超限后合并较早区间。
- 保留最近 1,000 道原题的精简统计；近期图表按每 20 题展示，详细日志仍最多保留 500 条并遵循原容量限制。
- 旧版按独立评估累计数保留原题总量，用仍存在的日志还原已知日期和诊断信息。缺少日期的早期原题单独说明；部分日期带 `*`，缺失历史不会补成零。
- 旧版没有有效用时和历史掌握度快照，不倒推或伪造；用时及掌握趋势从升级时开始。只有一个掌握度记录时显示基线说明。
- 导入严格校验统计版本、数值、日期和题号/日志锚点，重复导入不会再次累加。统计数据与原题评估、日志在同一份 Profile 中保存和导出。

## 验证

自动化使用生成的数据，覆盖独立/辅助计数、重复提交、复测、历史迁移、容量合并、计时暂停、跨午夜、导航与拆步状态保留，以及提交与计时写入并发。完整实际 React 作答模拟用于确认统计功能不改变完成课程所需的题目序列。

个人备份仅用于用户授权的本地临时预览，不放入测试文件、夹具或仓库。
